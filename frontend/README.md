# DocCheck frontend

Интерактивная реализация согласованного экрана на React, TypeScript, Vite и Tailwind. Владелец — Николай. Поддержан только явно обозначенный синтетический демо-режим.

## Запуск

Проверено на Node.js 26.12.1 / npm 11.6.2. Зависимости зафиксированы в package-lock.json. Тесты используют встроенную поддержку TypeScript в современной версии Node.js.

```sh
npm ci
npm run dev
```

Демо открывается на http://127.0.0.1:5173. Шрифты, PDF и PNG поставляются локально; внешние API и CDN при работе не нужны.

```sh
npm run typecheck
npm test
npm run build:demo
npm run preview
```

`build:demo` создаёт демонстрационный dist, `preview` показывает последнюю сборку на 127.0.0.1:4173. Обычный `npm run build` исключает demo-модуль и его документы, показывая «сервис не настроен». До подключения API это не готовое рабочее приложение. Демо нельзя использовать как скрытый fallback при ошибке API.

## Реализовано

- Две темы с сохранением выбора; R6/R10; мягкие badges; адаптивная компоновка.
- Таблица, фильтры, выбор строки, объяснение и формула, отсутствующие значения как «—».
- Два синтетических PDF с PNG-превью и точной рамкой суммы; масштаб и открытие оригинала.
- Источники и исключённый дубликат, клавиатурное переключение вкладок.
- Боковая панель с фиксированным демо-комплектом, имитация очереди/обработки и история текущей сессии. После перезагрузки история сбрасывается.
- JSON с presentation_only и печатный HTML с маркировкой синтетики; экспорт всех показателей независимо от фильтра.

## Граница с обработкой

`src/presentation.ts` — типы отображения, **не CheckResult**. `src/demo/fixture.ts` создан по утверждённому макету, не является эталоном или результатом OCR. Деньги заданы точными строками; frontend только форматирует их.

PDF и PNG созданы из вымышленных данных. Генератор: `../scripts/generate_demo_documents.py`, координаты: `src/demo/assets/locators.json`. Копия первого акта представлена как исключённый дубликат. Значения КФЗ пока находятся в фикстуре, отдельного PDF отчёта нет.
