# TypeScript frontend

Владелец направления — Николай. Здесь будет интерфейс загрузки, статусов обработки, таблицы сверки, источников и экспорта.

Основой типов результата станет общая JSON Schema из Linear. Планируемые пути: `../contracts/check_result.schema.json` и `../tests/fixtures/synthetic_result.json`. Оригинальные JSON пока не импортированы. Отображение фикстуры должно явно обозначать синтетический режим.

UI-библиотека, package.json и команды сборки будут добавлены в NRT-8. HTTP-контракт фиксируется в NRT-13. Денежная логика не переносится из Python во frontend.
