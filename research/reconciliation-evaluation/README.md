# Локальная оценка результатов сверки

CLI на Python 3.12 считает показатели по отдельно подготовленным
ожиданиям и наблюдениям. Библиотеки приложения, PostgreSQL и сеть
не нужны. Определения метрик ниже предназначены для технических
проверок. Андрей подтверждает их перед независимой приёмкой NRT-33.

## Входы

Оба файла — массивы UTF-8 JSON. Например, ожидания для одной
вымышленной строки:

```json
[{"case_id":"demo","indicator_id":"A","origin_group":"synthetic-1","split":"holdout","expected_status":"discrepancy"}]
```

Наблюдения для неё:

```json
[{"case_id":"demo","indicator_id":"A","status":"discrepancy","has_evidence":true}]
```

Статусы — `verified`, `discrepancy`, `unverified`. Пара
`case_id` и `indicator_id` уникальна в каждом файле. Ожидания
перечисляют целевые строки до прогона и позволяют проверить разделение
`development` и `holdout`. Владелец данных присваивает производным
одной исходной операции или пакета общий `origin_group`. CLI
отклоняет группу в обеих выборках и разбиение одного случая между
группами. Обнаружение общего происхождения по содержимому остаётся
за владельцем. Наблюдения относятся только к выбранной выборке.
Пропущенная строка учитывается как `missing`. Неизвестный или
повторный ключ приводит к ошибке. `has_evidence` сообщает о наличии
доказательства по внешней проверке. CLI не оценивает его качество.

```sh
python research/reconciliation-evaluation/evaluate.py --expectations evaluation/expected.json --observations evaluation/observed.json --split holdout
```

Закрытые входы остаются в среде владельца и вне runtime, CI и Git.
Публичные проверки используют только вымышленные данные. Результат
содержит общие числа и матрицу статусов без идентификаторов строк
или групп. При ошибке аргументов CLI сообщает о ней без передачи путей
или значений аргументов в stderr. Даже агрегаты закрытой выборки публикуются по решению
владельца. Независимые результаты не используются для настройки
правил, промптов или порогов. [Режим данных](../../docs/data-policy.md)

## Формулы

Числитель и знаменатель выводятся для каждой доли. При знаменателе
0 значение равно `null`. Строки имеют одинаковый вес. Число групп
показывает размер покрытия исходных случаев, статистические интервалы
CLI не вычисляет.

| Показатель | Числитель | Знаменатель |
| --- | --- | --- |
| Точность расхождений | Ожидалось и получено `discrepancy` | Получено `discrepancy` среди ожидаемых `discrepancy` и `verified` |
| Полнота расхождений | Ожидалось и получено `discrepancy` | Все ожидаемые `discrepancy`, включая пропущенные и непроверенные |
| Ложные подтверждения | Получено `verified` при ожидаемом `discrepancy` или `unverified` | Все полученные `verified` |
| Ложные тревоги | Получено `discrepancy` при ожидаемом `verified` | Все ожидаемые `verified` |
| Доля непроверенных | Получено `unverified` | Все ожидаемые строки |
| Покрытие ответами | Получен любой статус | Все ожидаемые строки |
| Покрытие определёнными ответами | Получено `verified` или `discrepancy` | Все ожидаемые строки |
| Наличие доказательств | Получен определённый ответ с `has_evidence=true` | Все полученные `verified` и `discrepancy` |

Полученные расхождения среди ожидаемых `unverified` видны отдельным
счётчиком и в матрице. Независимая разметка, мутации и итоговая оценка
качества проводятся отдельно от этого инструмента.

Проверки из папки `research/reconciliation-evaluation`:

```sh
python -m unittest discover -s tests -v
```
