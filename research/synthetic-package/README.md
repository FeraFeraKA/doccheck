# Генератор синтетического комплекта NRT-89

Создает 23 документа с вымышленными реквизитами: скан КФЗ, 10 XLSX-ведомостей, текстовые PDF, PDF-сканы, PNG, служебную записку и справку DOCX. Готовый набор: [docs/synthetic/nrt-89](../../docs/synthetic/nrt-89/README.md).

Старый локальный стенд содержит 192 синтетических первичных документа и 300 сценарных отчетов. Его файлы не перенесены: в них отсутствовала видимая синтетическая маркировка, генератор зависел от локальных путей, а структура предназначалась для отдельных OCR-экспериментов. Здесь сохранены подходы — фиксированный seed, генерация из вымышленных фактов, раздельное хранение входов и ожиданий — без импорта стенда, оригиналов или книги ответов.

## Запуск

Python 3.11+; зависимости из `requirements.txt`; Node.js 24+ и `@oai/artifact-tool` (проверена версия 2.8.148). Для PDF нужен TrueType-шрифт с кириллицей: генератор ищет DejaVu Sans / Liberation Sans на Linux и Arial на macOS/Windows. Другой шрифт задается `SYNTHETIC_FONT=/path/to/font.ttf`.

XLSX авторятся библиотекой `@oai/artifact-tool` из среды Codex. **Одной установки Python-зависимостей недостаточно.** На машине без этой библиотеки готовые XLSX можно использовать и проверять, но полная повторная генерация требует установленной среды с Artifact Tool. Библиотека не копируется в Git и не скачивается генератором. Это ограничение переносимости текущего генератора.

Из корня репозитория, после подготовки зависимостей:

```sh
python -m pip install -r research/synthetic-package/requirements.txt
python research/synthetic-package/generate.py --output artifacts/synthetic-890041
python research/synthetic-package/verify.py artifacts/synthetic-890041
```

Если Node и его пакеты не находятся стандартным способом, передайте `--node /path/to/node` и `ARTIFACT_TOOL_MODULE_DIR=/path/to/node_modules`. В Codex эти пути возвращает загрузчик workspace dependencies. Абсолютных путей конкретного пользователя в исходниках нет.

Вариация с другими суммами, договором, контрагентами и годом:

```sh
python research/synthetic-package/generate.py --seed 890042 --output artifacts/synthetic-890042
python research/synthetic-package/verify.py artifacts/synthetic-890042
```

Default seed: `890041`. Диапазон seeds: 0–99999999. Папка назначения должна быть пустой: опубликованный комплект и результаты других прогонов не перезаписываются. `--previews artifacts/synthetic-preview` дополнительно сохраняет превью XLSX вне комплекта. Генератор не открывает `docs/case`, `data`, локальный архив или эталон организаторов; интернет и OCR для генерации не нужны. Арифметика модели — целые копейки и Python Decimal. В XLSX суммы экспортируются числами с двумя десятичными знаками, итог остается формулой `ROUND(SUM(...),2)` с проверенным кэшем.

## Файлы и граница обработки

- `inputs/`: только 23 документа, каждый с видимой пометкой «СИНТЕТИЧЕСКИЙ ДОКУМЕНТ».
- `inputs.json`: разрешенный список документов с SHA-256; только этот список должен читать загрузчик.
- `expectations/manifest.json`: факты каждого файла, причины исключения, состав подтверждений и ожидаемые статусы; только для тестов и человека.
- `README.md`: инструкция набора; не вход модели.

Формат `fixture-1` — локальный манифест тестового набора. Это не новый контракт API/CheckResult и не подмена несогласованной схемы приложения.

Ожидания задаются проектированием фикстуры. Они не вычислены продуктовым pipeline и не являются независимым holdout. Показатели `payroll` и `production_overhead` подтверждены; `insurance` имеет ненулевую дельту; `general_admin` непроверяем из-за отсутствующего приложения; `other` — из-за отсутствующих документов. Дубль `10_admin_copy` совпадает байт-в-байт с `09_admin_act`. `13_transfer` относится к другому договору, `14_admin_act` — к следующему месяцу вне периода. У `general_admin` сумма доступных документов специально равна сумме отчета; это **не** делает комплект полным.

## Проверки

```sh
python research/synthetic-package/verify.py docs/synthetic/nrt-89
python -m unittest discover -s research/synthetic-package/tests -v
git diff --check
```

Верификатор проверяет список файлов и хеши, отделение разметки, текстовый/скановый характер PDF, значения и формулы XLSX, даты, видимую маркировку нативных форматов, идентичность дубля и точные суммы статусов. Маркировку и расположение текста в сканах проверяют по рендерам; OCR и приложение этим тестом не запускаются. Запускайте Python без `-O`, поскольку проверки используют assertions.

`test_package.py` дополнительно проверяет обнаружение измененного PDF, лишнего файла с ответами и неверной ожидаемой суммы. Seeds 890041/890042 сохраняют список файлов и типы ситуаций, меняя содержимое. Бинарная идентичность между версиями библиотек/шрифтами не обещается; содержание определяется seed, версии зависимостей влияют на экспорт.

## Разметка форм и приемка

Расположение полей фиксировано между seeds:

| Формат | Поля |
| --- | --- |
| КФЗ PDF, страница 1 | Сверху договор, организация и период; ниже пять строк затрат, сумма каждой справа; внизу общий итог |
| Первичный PDF/PNG, страница 1 | Заголовок, номер/дата, договор, стороны и учебный ИНН; период; назначение; сумма; полнота приложения |
| XLSX, лист `Ведомость` | A1 маркировка, A2 заголовок, A3 номер/договор, A4 организация, A5 период; A8:D8 заголовки, B9:B11 исполнители, C9:C11 даты, D9:D11 начисления, D13 итог |
| DOCX | Маркировка в колонтитуле; заголовок и реквизиты в абзацах; первая таблица с суммой и итогом |

**Это новые упрощенные формы, не доказанная копия структуры оригинала.** Критерий NRT-89 «поля стоят там же» пока требует локальной проверки Андрея. Он должен подтвердить типы документов, набор полей/столбцов и их позиции либо передать список необходимых изменений без исходных значений. Отсутствие совпадений существенных реквизитов/сумм также подтверждается только локально. Учебные `SYN-INN` и будущие даты помогают отделить фикстуру от реальных данных, но не заменяют сравнение.

После принятия комплекта Николай отдельно удаляет `docs/case/examples/` и обновляет ссылки в AGENTS.md, README и тестах, как указано в NRT-89. Этот PR добавляет только набор, генератор и документацию; не заявляет удаление оригиналов или прохождение продуктового pipeline.
