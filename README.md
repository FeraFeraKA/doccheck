# DocCheck

Локальная сверка карточки фактических затрат (КФЗ) с первичными документами: извлечение, точные расчёты и доказательства расхождений.

Проект команды **«Буткемперы»**, хакатон МФТИ, трек 5.

## Текущий этап

Реализован интерактивный frontend: две темы, таблица сверки, фильтры, синтетические источники, боковая панель, история текущей сессии и демо-экспорт. API, OCR и worker пока отсутствуют. Канонический контракт из Linear ещё не получен; демонстрация использует отдельные presentation-типы по согласованному макету.

## Структура

```text
backend/             Python: API, worker, обработка и денежная логика
frontend/            TypeScript: пользовательский интерфейс
contracts/           Источник и правила общего контракта (импорт JSON ожидается)
docs/                Архитектура и правила разработки
tests/fixtures/      Место для синтетических примеров
data/                Локальные оригиналы, превью и результаты; вне Git
```

## Начало работы

```sh
git clone https://github.com/FeraFeraKA/doccheck.git
cd doccheck
```

```sh
git diff --check
```

Для запуска демо (проверено на Node.js 26.12.1 / npm 11.6.2):

```sh
cd frontend
npm ci
npm run dev
```

Открыть адрес Vite, по умолчанию http://127.0.0.1:5173. Демо не принимает реальные файлы и не выполняет OCR. Режимы сборки и проверки описаны в [frontend/README.md](frontend/README.md).

Репозиторий публичный: клонирование доступно без приглашения. Права на запись участникам выдаёт владелец; публичность не даёт права push. Исходные документы и секреты в репозитории не хранятся.

Шаблон окружения — `.env.example`; порядок заполнения и текущие ограничения описаны в [настройках окружения](docs/environment.md).

## Планируемый стек

Согласованы React + TypeScript + Vite + Tailwind CSS; Python/FastAPI, отдельный worker, SQLAlchemy + Alembic и PostgreSQL. База будет хранить задания, метаданные и результаты; документы — в согласованной локальной среде обработки. Redis и внешний LLM для MVP не требуются. Backend, Docker Compose и миграции ещё предстоит реализовать.
