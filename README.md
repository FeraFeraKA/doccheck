# DocCheck

Локальная сверка карточки фактических затрат (КФЗ) с первичными документами: извлечение, точные расчёты и доказательства расхождений.

Проект команды **«Буткемперы»**, хакатон МФТИ, трек 5.

## Текущий этап

Подготовлена структура репозитория по NRT-6. Приложение, API, OCR и worker пока не реализованы. Импорт схемы и синтетической фикстуры из Linear пока заблокирован: ссылки возвращают HTML вместо JSON.

## Структура

```text
backend/             Python: API, worker, обработка и денежная логика
frontend/            TypeScript: пользовательский интерфейс
contracts/           Источник и правила общего контракта (импорт JSON ожидается)
docs/                Архитектура и правила разработки
tests/fixtures/      Место для синтетических примеров
data/                Локальные оригиналы, превью и результаты; вне Git
```

## Начало работы

```sh
git clone https://github.com/FeraFeraKA/doccheck.git
cd doccheck
```

```sh
git diff --check
```

Для приватного репозитория владелец выдаёт участникам доступ; каждый проверяет клонирование под своим аккаунтом. Успешное клонирование владельцем не подтверждает доступ остальных участников.

## Планируемый стек

TypeScript frontend, Python/FastAPI и отдельный Python worker, PostgreSQL. Оригиналы хранятся локально; PostgreSQL хранит задания, метаданные и результаты. Redis и внешний LLM для MVP не требуются. Docker Compose и миграции будут добавлены в задачах каркаса и API. UI-библиотека пока не выбрана.
