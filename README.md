# DocCheck

Локальная сверка карточки фактических затрат (КФЗ) с первичными документами: извлечение, точные расчёты и доказательства расхождений.

Проект команды **«Буткемперы»**, хакатон МФТИ, трек 5.

## Текущий этап

Подготовлены структура репозитория и минимальный frontend-каркас с тестовой инфраструктурой. Загрузка документов, API, OCR и worker пока не реализованы. Присланные схема и примеры доступны для рассмотрения; общий контракт ещё не зафиксирован. Агенты могут подготовить его техническую версию с независимым ревью для ночной работы; человеческая приёмка проводится отдельно.

## Структура

```text
backend/             Python: API, worker, обработка и денежная логика
backend/tests/       Тесты backend и инструкции для них
frontend/            TypeScript: пользовательский интерфейс
frontend/tests/      Тесты frontend и инструкции для них
contracts/           Решения по общему контракту после согласования
docs/                Архитектура и правила разработки
data/                Локальные оригиналы, превью и результаты; вне Git
```

## Начало работы

```sh
git clone https://github.com/FeraFeraKA/doccheck.git
cd doccheck
```

```sh
git diff --check
```

Для приватного репозитория владелец выдаёт участникам доступ; каждый проверяет клонирование под своим аккаунтом. Успешное клонирование владельцем не подтверждает доступ остальных участников.

## Планируемый стек

Frontend: React, TypeScript, Vite, React Router, Zustand, Tailwind CSS и собственные компоненты; менеджер пакетов — pnpm. Подробности и статус настройки — в [frontend/README.md](frontend/README.md). Backend: Python/FastAPI, отдельный Python worker и PostgreSQL. Оригиналы хранятся локально; PostgreSQL хранит задания, метаданные и результаты. Redis и внешний LLM для MVP не требуются. Docker Compose и миграции будут добавлены в задачах каркаса и API.
