# DocCheck

DocCheck помогает бухгалтеру сверять карточку фактических затрат (КФЗ) с первичными документами. В результате видны суммы по статьям, расхождения и ссылки на источники.

Проект команды «Буткемперы», хакатон МФТИ, трек 5.

## Запуск каркаса через Docker Compose

Нужны Git, запущенный Docker с Linux-контейнерами и Docker Compose с поддержкой `up --wait`. Первая сборка скачивает образы и зависимости.

```sh
git clone https://github.com/VCyberPunk2077/doccheck.git
cd doccheck
```

Если файла `.env` ещё нет, скопируйте в него `.env.example`. В Linux и macOS выполните `cp .env.example .env`, в PowerShell — `Copy-Item .env.example .env`. Задайте в `.env` пароль `DOCCHECK_DB_PASSWORD` из случайных латинских букв и цифр.

```sh
docker compose up --build --wait
```

Откройте [DocCheck](http://127.0.0.1:8080) или [готовый учебный пример](http://127.0.0.1:8080/checks/synthetic-example) без загрузки файлов. Доступность API и базы проверяет [`/health`](http://127.0.0.1:8080/health). Если порт занят, измените `DOCCHECK_PORT` в `.env`. Команда `docker compose down` останавливает приложение и сохраняет файлы и историю.

## Текущий этап

После нажатия «Запустить проверку» загруженный пакет встаёт в очередь. Для расчёта по своим документам подключите отдельный обработчик. Для запуска обработчика v3.2 через Compose нужны образ с адаптером и доступ к локальной модели. В сохранённом результате доступны источники, оригиналы файлов и экспорт XLSX. [Настройка обработчика](backend/README.md#отдельный-документный-worker-в-compose)
