# DocCheck

DocCheck помогает бухгалтеру сверять карточку фактических затрат (КФЗ) с первичными документами. Он показывает суммы по статьям, расхождения и источники каждого значения. Если подтверждений недостаточно, статья остаётся непроверенной.

Проект команды «Буткемперы», хакатон МФТИ, трек 5.

## Запуск каркаса через Docker Compose

Нужны Docker с Linux-контейнерами и Docker Compose с поддержкой `up --wait`.

```sh
git clone https://github.com/VCyberPunk2077/doccheck.git
cd doccheck
```

Скопируйте `.env.example` в `.env` и задайте `DOCCHECK_DB_PASSWORD`: используйте случайную строку из букв и цифр. Затем выполните:

```sh
docker compose up --build --wait
```

Откройте [DocCheck](http://127.0.0.1:8080) или сразу [готовый учебный пример](http://127.0.0.1:8080/checks/synthetic-example). Если порт занят, измените `DOCCHECK_PORT` в `.env`. Для остановки выполните `docker compose down`; загруженные файлы и история сохранятся.

Готовый пример работает без распознавания документов. Загруженные пакеты остаются в очереди, пока не запущен обработчик документов. Для реальной сверки см. [локальный запуск с Qwen и LoRA в WSL](backend/README.md#сверка-с-qwen-и-lora-в-wsl) или [подключение обработчика к Compose](backend/README.md#отдельный-документный-worker-в-compose).
