# Режим данных

`data/` — локальная директория, полностью исключённая из Git. Создать её после клонирования: `mkdir data`. В этой директории можно разделять разрешённые для локального прогона оригиналы, превью и результаты.

Независимые эталоны и holdout хранятся отдельно от runtime. Их нельзя включать в образы, фикстуры API или подсказки для вычисления результата.

В Git разрешены исходный код, согласованная общая схема и явно синтетические примеры. Разрешены работа с обезличенными документами конкретного комплекта и размещение его примеров в `docs/case/examples/`; книга правильных ответов туда не входит. Это разрешение не распространяется автоматически на другие наборы. Исключение каталога через .gitignore не проверяет содержимое файлов в других местах: перед коммитом нужно просматривать diff и список файлов.

Не публиковать другие первичные документы, OCR-текст, скриншоты с их содержимым, реальные результаты, секреты и подробные логи. До подтверждённого разрешения облачным агентам передаются только код, синтетика и допустимые технические сообщения; разрешённый комплект указан выше. Выдача архива на хакатоне сама по себе не делает другие документы открытыми.

Приложение должно обрабатывать документы локально без внешних сервисов. Зависимости и веса можно подготовить до рабочего запуска. Проверка такого режима ещё предстоит.
