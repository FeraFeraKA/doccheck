# Согласованный интерфейс

Решения согласованы с Николаем в чате 11.11.2026 до реализации.

- React + TypeScript + Vite, Tailwind CSS. Backend: FastAPI, SQLAlchemy + Alembic, PostgreSQL, отдельный Python worker.
- Две темы с переключением. Светлая: фон #F4F7F6, поверхность #FFFFFF, акцент #0F766E. Тёмная: фон #0F172A, поверхность #182235, акцент #60A5FA.
- Контролы и badges R6; панели R10. Мягкая заливка статусов без рамки, непрозрачные текст и значок.
- Свободные отступы: внешние поля около 32 px, секции и панели 24 px, строки таблицы 56 px.
- Контекст сверху, таблица с объяснением слева, источник с выделенной суммой справа. На узком экране панели идут последовательно; таблица прокручивается отдельно.
- «Новая проверка» открывает боковую панель поверх результатов.
- Текущий этап — синтетический демо-интерфейс. Реальная интеграция после получения контракта и API. Демо нельзя выдавать за обработку пользовательских файлов.
- Неопределённые архитектура, дизайн, layout и scope обсуждаются до реализации.
