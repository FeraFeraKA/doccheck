# Синтетические данные

[Комплект NRT-89](nrt-89/README.md) содержит КФЗ и 22 подтверждающих документа с вымышленными данными. Для загрузки используйте только [inputs.json](nrt-89/inputs.json). Ожидания находятся отдельно в `nrt-89/expectations/`.

[Генератор и проверки](../../research/synthetic-package/README.md) описывают зависимости, seeds, состав ситуаций и ограничения. Это публичная регрессионная фикстура, не независимый эталон и не результат работы приложения.

Перед заменой комплекта организаторов Андрей локально проверяет соответствие структуры и отсутствие совпадающих существенных значений. Удаление оригинальной папки и переключение общих ссылок выполняет Николай отдельным PR после принятия этого набора.
