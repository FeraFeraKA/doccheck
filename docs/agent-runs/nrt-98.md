# NRT-98 — жизненный цикл очереди пакетов

[Задача Linear](https://linear.app/andreiakimov/issue/NRT-98/worker-nadyozhnyj-zhiznennyj-cikl-i-vosstanovlenie-zadanij)
прочитана 13 ноября 2026 года. Техническая база — `main`
`3b199025ffa678c7d41fe74950f855b91f36ada7` после NRT-96.

## Цель и критерии

Обеспечить устойчивое выполнение и восстановление сохранённых заданий
отдельным worker.

- [ ] Worker безопасно выбирает задание и фиксирует согласованные переходы
  состояний. Тяжёлая обработка не выполняется в HTTP-запросе.
- [ ] Ошибка обработчика записывается с безопасной причиной. Доступные
  частичные ошибки сохраняются.
- [ ] После перезапуска прерванное задание получает понятный статус ошибки,
  а очередь продолжает работу.
- [ ] Успех, ошибка и восстановление проверены на детерминированном
  тестовом обработчике.

## Изменения

- Миграция `0003_run_lifecycle` добавляет время начала и окончания,
  результат и техническую ошибку в `runs`.
- `run_document_worker` принимает обработчик явно. Сессионная блокировка
  PostgreSQL ограничивает очередь одним worker в схеме. Транзакция захвата
  сохраняет `processing` перед вызовом обработчика, отдельная транзакция
  сохраняет результат или ошибку. Вход и результат сверяются по ID задания,
  области и хешам файлов. Ошибки файла остаются в результате
  `completed_with_issues`.
- Следующий процесс после остановки владельца помечает оставшиеся
  `processing` как `failed` с кодом `worker_interrupted` и берёт
  следующий `queued`. Новый пользовательский запуск требует нового ключа
  идемпотентности. Файлы ранее принятого пакета сохраняются.

## Проверки и ограничения

На Python 3.12.12 и PostgreSQL 18.4 под Windows прошли 130 тестов
`uv run --frozen --with jsonschema==4.26.0 pytest tests --ignore=tests/ml_module -q`.
Шесть сценариев очереди покрывают успешный и частичный результат,
безопасную ошибку, несоответствие хеша файла, конкуренцию и восстановление
после принудительной остановки отдельного процесса. Ruff check, Ruff format,
`docker compose config --quiet` и `git diff --check` прошли.
Pytest сообщил известное предупреждение Starlette TestClient про httpx.

Штатный CLI запускает синтетический каркас. Подключение рабочего адаптера
и отдельный сквозной прогон относятся к NRT-95 и NRT-43. Маршруты выдачи
состояния и результата относятся к NRT-97. Docker daemon локально
недоступен. Следующий шаг — техническое ревью на актуальной базе.
