# NRT-90: подготовка ночного harness

- Задача: подготовить координатора и два независимых рабочих чата на разных устройствах, не создавая отдельный обязательный процесс Codex.
- Изменения: инструкции в `docs/agents/nightly/`; общие правила, описание контракта и инструкции ревью приведены к решению о техническом согласовании агентами и ночной ветке.
- Проверки: локальная проверка diff и ссылок; отдельный локальный `codex exec` под входом ChatGPT прочитал NRT-90 через Linear. Это проверяет один процесс и одну учётную запись, а не доставку заданий второму устройству.
- Ограничения: плановые продолжения обоих рабочих чатов, автоматическое распределение, PR в ночную ветку, CI и независимое ревью на реальном head требуют контролируемого пилота на двух устройствах. API Linear, работа второго аккаунта и выбранный срок назначения нельзя считать проверенными только по документации.
- Следующий шаг: опубликовать проверенную ветку инструкций, запустить координатора и два отдельных чата, выполнить NRT-104 и NRT-105 и зафиксировать фактический результат и ограничения.
