# NRT-107 — компактная навигация

[NRT-107](https://linear.app/andreiakimov/issue/NRT-107) сверена 14 ноября
2026 года. База DocCheck — `573420c`. Источник — [диапазон
`a912f25…d27978d`](https://github.com/ananakimov/project-placeholder/compare/a912f256231a85485a283d07b6c21295030c08a6...d27978dcb6b950964136b7dc1ef1dfe1fb9f7c1b),
в частности навигация из `e116bd3`.

Разметка `src/components/layout/Sidebar.tsx` перенесена в
`frontend/src/pages/checks/Sidebar.tsx`, адаптивные правила — в
`accountant-workspace.css`. Широкий экран показывает панель значков,
которая раскрывается поверх содержимого. На телефоне меню открывает
кнопка. Escape сворачивает меню и возвращает фокус. «Проверка системы»
доступна на обоих размерах.

Этот срез меняет только навигацию. Результат и очередь сверяются с #82 и
#83. Постоянная правая панель затрагивает экран результата, который
одновременно меняется в #82. Сценарии принятия, архива и версий требуют
согласованных серверных операций.

Браузерные сценарии проверяют раскрытие поверх страницы, мобильное меню,
возврат фокуса и доступ к проверке системы на 320, 700, 701 и 1440 px.
Прошли 146 Vitest, 38 Playwright, lint, проверка типов, обычная и публичная
сборки и `git diff --check`.
