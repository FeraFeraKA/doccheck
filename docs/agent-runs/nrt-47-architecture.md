# NRT-47 — архитектура DocCheck

[Задача Linear](https://linear.app/andreiakimov/issue/NRT-47/arhitektura-po-fakticheski-realizovannomu-resheniyu)
сверена 14 ноября 2026 года. [Архитектура](../architecture.md) описывает
`main` `55da39c20491ea52ddbfb514000cc6e35ed60df3`.

Границы API, worker и хранилища сверены с исходниками и OpenAPI. Путь данных
опирается на модули привязки наблюдений, планирования побайтовых дублей,
точного суммирования и сравнения и формирования заключения. Панель источника
сверена с кодом после [PR #71](https://github.com/VCyberPunk2077/doccheck/pull/71)
и [PR #73](https://github.com/VCyberPunk2077/doccheck/pull/73). Запросы оригинала
и адреса стартуют при открытии панели сохранённого результата. Скачивание
и открытие PDF выполняются по ссылкам после получения оригинала.

Проверены 23 относительные ссылки архитектуры, 10 маршрутов React Router и
`git diff --check`. Изменения только в документации. Подключение штатного
`process_package`, рабочие OCR и финансовая сверка, приёмка владельцами
и состояние публичного деплоя этим срезом не подтверждаются.
