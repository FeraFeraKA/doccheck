# NRT-108 — инструкция запуска закрытого гибридного Preview

[Задача Linear](https://linear.app/andreiakimov/issue/NRT-108/razvernut-demo-doccheck-na-vercel-i-render).
Дата проверки — 14.11.2026. Базовая реализация — PR #96 и #98.

- `docs/hosted-preview.md` описывает выделенный Render workspace с PostgreSQL,
  Vercel Preview, связь с воркером, приёмку и откат. README ссылается на эту
  инструкцию. Документ архитектуры отражает текущее состояние протокола.
- `scripts/run-v32-hosted-worker.ps1` проверяет origin, API и установленную
  модель, читает секрет воркера из окружения процесса или через скрытый ввод,
  запускает существующий адаптер.
- Vite Preview собран с `pnpm@12.14.0` и неизменённым lockfile. Конфигурация
  маршрутизации проверена локально. Blueprint проверен по опубликованной
  схеме Render.
- В отдельном локальном PostgreSQL API применил миграции и подготовил комплект
  двум участникам. Воркер дважды вызвал реальную локальную Qwen на XLSX и DOCX.
  Chromium через loopback HTTPS подтвердил вход, результат, cookie, источники,
  выделение, скачивание оригинала и XLSX в каждом сеансе.
- Выделенный проект Vercel и Render workspace подготовлены на уровне
  инструкций. Для облачной приёмки нужны отдельные ресурсы, доступы и
  фактический `/health` на выделенной БД. Render CLI не выполнил проверку
  конкретного workspace без выбранного workspace. Публичный стенд не использован.
