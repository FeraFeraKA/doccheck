# Проверка документации DocCheck

[Быстрый запуск](../../README.md#запуск-каркаса-через-docker-compose) описывает локальный запуск приложения. [Демо](../demo-runbook.md) открывает готовый учебный результат, а [сценарии сверки](../case/use-cases.md) задают входы и контрольные суммы для проверки обработчика.

Проверены ссылки, контрольные суммы учебного комплекта и создание повреждённого PDF. Демо открывается в браузере из локальной сборки и по публичной ссылке.
