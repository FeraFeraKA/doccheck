# Подготовка публичных материалов кейса

- Задача: сделать описание кейса, два сценария, план выступления и план пилота
  понятнее внешнему читателю, сохранив происхождение уточнений и ограничения.
  Контекст: [сценарии сверки](https://linear.app/andreiakimov/issue/NRT-48/dva-use-case-s-vhodom-i-ozhidaemym-rezultatom)
  и [сценарий демо](https://linear.app/andreiakimov/issue/NRT-53/pitch-na-3-minuty-i-zhivoe-demo).
- Изменены `docs/case/README.md`, `docs/case/use-cases.md`,
  `docs/demo-runbook.md` и `docs/pilot-roadmap.md`: имена заменены ролями,
  исторические проверки отделены от текущих возможностей, добавлены ограничения
  сканированной КФЗ и статусов доступного адаптера.
- Проверки: `git diff --check` без ошибок; скрипт проверил 31 локальную ссылку
  вместе с якорями. Проверены SHA-256 всех 23 файлов синтетического комплекта.
  Команда генератора повреждённых файлов из сценария выполнена успешно;
  результат создан в игнорируемом `data/negative-fixtures-check/`.
  У одностраничной синтетической КФЗ не найдено извлекаемого текста.
- Ограничения: работа касалась документации. Модель, полная сверка пакетов,
  текущая доступность облачного демо и предметная приёмка не проверялись.
- Следующий шаг: независимое ревью изменений и отдельное подтверждение
  сквозных сценариев с подходящим обработчиком.
