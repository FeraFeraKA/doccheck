# NRT-90: очистка комментариев завершённой задачи

- В инструкции ночных агентов добавлены блок состояния в описании NRT-90, подтверждение освобождения задания и очистка собственных технических комментариев после фиксации результата.
- Уточнены проверка авторства двух слотов, восстановление незавершённой очистки после STOP и реестр результатов для поздно появившихся сообщений. Тексты для участников обновлены; правила содержательного ревью не менялись.
- Read-only проверено: Linear MCP предоставляет `get_user`, `get_issue`, `save_issue` с `patch` и `delete_comment`; текущая учётная запись и авторы комментариев имеют идентификаторы. Пример фильтра из инструкции прочитал историю NRT-90 через две страницы и сохранил в выводе комментарий старого назначения, присутствующий в тестовом реестре, а также STOP/STOPPED.
- Пример фильтра из инструкции проверен также на десяти синтетических комментариях: события активного запуска, поздние сообщения завершённых назначений, STOP, повреждённые записи и `RELEASE_OLD` отобраны; нерелевантные старые события и обычное сообщение человека не попали в вывод.
- Независимое ревью обнаружило риски совпадения авторов, перезаписи описания, отложенной очистки и пропуска старых событий; инструкции уточнены. Повторный вердикт по локальному дереву — `pass`; это не ревью PR и не приёмка пилота.
- Фактическая запись блока в NRT-90, удаление комментариев, права аккаунта второго устройства и пилот с двумя чатами не проверялись. Существующие комментарии и задача в Linear в этой работе не изменялись.
