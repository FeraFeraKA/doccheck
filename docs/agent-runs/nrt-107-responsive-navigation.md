# NRT-107 — адаптивная навигация с компактной панелью

[NRT-107 в Linear](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck)
сверена 14.11.2026. База `6701fe17e424d9c7180c3b3eecde2fefd7f521f7`.
[Диапазон источника](https://github.com/ananakimov/project-placeholder/compare/5a854c837f1f999b9d6769deeca751e146b4f96d...e4e63443af9037d3043a8574b69cbc198ab04f2b)

Задача требует переносить применимые визуальные изменения отдельными PR,
сохраняя React Router, Vite, pnpm, один путь бухгалтера, действующий API,
ограничение публичной загрузки, адресные доказательства и явную синтетику.
Этот срез меняет только оболочку. Сверка, очередь и серверные операции
остаются в отдельных задачах.

`src/components/layout/Sidebar.tsx` и правила из
`src/styles/workspace.css` перенесены в `Sidebar.tsx` и
`accountant-workspace.css`. При ширине от 701 px панель занимает 64 px
и раскрывается поверх страницы до 220 px. На планшете без наведения
раскрытие управляется логотипом. До 700 px логотип открывает меню в
потоке страницы. Escape возвращает фокус логотипу из открытого мобильного
меню. После выбора раздела на телефоне фокус тоже возвращается логотипу.
Прежняя прокрутка низкой боковой панели и «Проверка системы» сохранены.

Chromium проверил 320, 700, 701, 768, 1250, 1251 и 1650 px, планшет с
сенсорным вводом, Tab и переход к «Проверке системы» при 768×200,
доступ к пагинации при раскрытой панели и Escape в поиске и модальном
режиме. Использованы синтетические HTTP-ответы. Прошли lint, typecheck,
сборка, 146 Vitest, 48 Playwright и `git diff --check`.

По [замечанию #88](https://github.com/VCyberPunk2077/doccheck/pull/88#issuecomment-6874083957)
панель сужается сразу при закрытии. Анимация раскрытия сохраняется.
В Chromium при 1280×900 клик по координатам ссылки «Все проверки» сразу
после Escape открывает список. Тот же тест со стилями `f538d4c` открывал
мастер. Повторно прошли lint, typecheck, сборка, 146 Vitest и 49 Playwright.
