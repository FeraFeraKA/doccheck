# NRT-83 — перенос интерфейса Lovable

[Задача Linear](https://linear.app/andreiakimov/issue/NRT-83/proverit-i-vstroit-interfejs-lovable-v-frontend)
и комментарий Андрея прочитаны 13 ноября 2026 года.
[Источник](https://github.com/ananakimov/project-placeholder/tree/163f6367f91d9885b16685f0981290874858e955)
проверен на указанном коммите `163f636`. Следующий коммит источника относится к публикации.

Из источника взяты композиция и палитра рабочей области, боковая навигация,
переключатель ролей, двухшаговый выбор файлов, обзор и раскладка сверки
с таблицей рядом с адресом доказательства. Доступны разделы документов,
исключений и заключения. Маршруты используют существующий React Router.
Отдельный стартовый экран синтетического каркаса доступен по прежнему URL.

Исходник использует TanStack Start, React Query, компоненты Radix, общий
контекст правок и подписания, зашитые результаты и ответы панели «Почему?».
Перенесённая реализация использует локальное состояние для выбранных
файлов, роли и источника. Интерфейс обозначает доступность журналов.
Правки, подписание, ответы «Почему?», просмотр оригиналов, экспорт и
действия рабочего API требуют отдельных решений или задач. Переключатель
ролей управляет представлением и не выполняет авторизацию.

Для выбора примера используются имена из NRT-89, для результата — отдельная
фикстура NRT-86. Интерфейс явно разделяет выбор локальных файлов и переход
к готовой фикстуре. Суммы форматируются из строк, отсутствие значения
показано прочерком. Просмотр источника показывает структурный адрес из
контракта. Vite и Docker получают только два файла синтетики из репозитория.

## Проверки

- Node 26.12.1, pnpm 12.14.0. `pnpm install --frozen-lockfile`,
  `pnpm typecheck`, `pnpm test` (13 тестов), `pnpm build` прошли.
- Playwright в установленном Chrome — 4 сценария, включая выбор примера,
  ноль и отсутствующее значение, выбор адреса доказательства, прямой переход
  в подраздел, мобильную раскладку и отсутствие API-запросов в новом UI.
- `git diff --check` прошёл. Docker daemon локально недоступен,
  контейнерная сборка не проверена локально.

После первого ревью добавлены публичные экспорты среза, поддержка выбора
файлов без secure-context API и отдельное представление исключений для
роли бухгалтера. Compose CI проверяет присутствие двух разрешённых
фикстур и отсутствие исходных документов, данных и ожиданий NRT-89.
Повторно прошли typecheck, 13 тестов Vitest, сборка и 5 сценариев Playwright
на закреплённом Chromium.

По повторному отзыву обе роли видят список исключений. Для аспиранта
показан режим просмотра. Для бухгалтера показано, что действия недоступны
на синтетике. Playwright проверяет данные и состояние для обеих ролей.
