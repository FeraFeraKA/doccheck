# NRT-37 — регрессия частичного результата

[NRT-37](https://linear.app/andreiakimov/issue/NRT-37/status-neprovereno-s-prichinoj)
прочитана 14 ноября 2026 года. База `9738e95ccfc73710abcfaddc80250ca3a3793743`.

В `backend/tests/test_result_contract.py` добавлен синтетический вариант
действующего примера. В одном `completed_with_issues` запуске статья A
остаётся `verified` при полном основании и нулевой дельте. По статье B есть
отдельно подтверждённое слагаемое, а обязательный для неё файл не прочитан.
Статья остаётся `unverified` с известной частичной суммой, `null` в ожидаемом
значении и дельте. Связь от строки через первичное замечание до конкретной
ошибки файла и адресного доказательства сохраняется после записи и чтения
JSON. Вариант и сериализованное представление проходят Draft 2020-12 и
Pydantic.

`uv run --frozen pytest tests/test_result_contract.py -q` — 103 теста прошли.
Ruff и `git diff --check` прошли. Сценарий фиксирует полноту и независимость
как входные условия синтетического теста. Определение релевантности,
трудоёмкости и полноты в обработчике остаётся в предметном срезе NRT-37.
