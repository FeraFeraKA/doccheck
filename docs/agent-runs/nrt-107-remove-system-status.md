# NRT-107. Логотип и удаление экрана проверки системы

Дополнение по обратной связи Николая к [NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck). Контекст Linear прочитан 14.11.2026; задача отмечена Done. База DocCheck `e454fa91978527a5fb0051e3b504a9a37db08d90` после #108. Основание для этого среза — обратная связь по локальной сборке.

- `Sidebar.tsx`, `accountant-workspace.css` и `WorkspaceIcon.tsx` убирают пункт диагностики и восстанавливают подпись `doccheck` при раскрытии панели и на мобильном.
- `App.tsx` ведёт старую ссылку `/system-status` в `/checks/new`. Из `ChecksWorkspace.tsx` убрана мобильная ссылка. Удалены отдельная страница диагностики, её клиент и тесты.
- Сценарий Compose проверяет переход в браузере, затем вызывает `/health` и отслеживает синтетическое задание через API. Проверка сохранения результата после перезапуска остаётся частью CI.

Локально прошли `pnpm lint`, рабочая и публичная сборки с проверкой типов, 142 теста Vitest и 58 тестов Playwright. При первом полном запуске один сценарий раскрытия показателя завершился по тайм-ауту; сценарий прошёл пять изолированных повторов и следующий полный прогон. В расширении Brave старая ссылка открыла «Новую проверку», в меню остались новая проверка, список и архив. `GET /health` на локальном стеке вернул `ok` для API и PostgreSQL.

Конфигурация Compose и синтаксис встроенного в workflow JavaScript проверены локально. Docker Engine в локальном сеансе недоступен. Полный цикл Compose выполняется в GitHub Actions перед слиянием.
