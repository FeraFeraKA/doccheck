## Изменения

- [4557732553](https://github.com/VCyberPunk2077/doccheck/pull/8#discussion_r4557732553):
  выбор исходной суммы учитывает роль поля. Итог имеет приоритет над общей суммой;
  разные итоги сохраняются как конфликт с evidence, а не разрешаются порядком
  строк или ответом модели. `null` блокирует подстановку модели, конфликт виден
  в отдельной карточке проверки. Полнота нативного пакета и повторное чтение одного
  фрагмента не снимают конфликт. Равные Decimal и явный ноль не теряются.
- [4557732567](https://github.com/VCyberPunk2077/doccheck/pull/8#discussion_r4557732567):
  пустая роль исполнителя связывается со следующей строкой только при допустимом
  соседстве адресов; обе строки сохраняются в evidence.
- [4557732577](https://github.com/VCyberPunk2077/doccheck/pull/8#discussion_r4557732577):
  необязательный знак `№` после явной подписи номера удаляется перед проверкой
  значения. Настоящие префиксы `N`/`No` не удаляются.

Изменены `identity_v2.py`, очереди в `identity_v3.py`/`identity_v4.py`, защита исправления суммы
в `identity_v4_source.py`, README и синтетические регрессионные тесты.
Независимый агент написал первоначальные 17 тестов через публичный API и
воспроизвёл 27 ошибочных сценариев до исправления. Дополнительные тесты проверяют
конфликты, источники, границы адресов и отсутствие скрытого объединения.

Независимое ревью дополнительно выявило перенос номера после строки с `№`,
отсутствие карточки конфликта в низкоуровневой очереди v3 и пропуск итогов с
уточнениями «по документу»/«с НДС». Эти случаи исправлены и покрыты регрессиями.
Нераспознанный формат итогового поля остаётся неизвестным и не продвигает
промежуточную сумму; явный итог по разделу не считается общим итогом.

## Проверка и ограничения

Команды: `python -m unittest discover -s backend/tests/ml_module -q` с
`PYTHONPATH=backend/ml_module/src` на Python 3.12 и 3.14; `python -m doccheck_ml demo`;
`git diff --check`. Итоговое число тестов, точный SHA независимого ревью и CI
зафиксированы в описании PR.

Разрешённые примеры изучены как контекст структуры; новые тесты используют только
сгенерированные временные файлы. Модели, обучение и изменение весов не выполнялись.
Финансовая полнота, рабочий GPU-инференс и человеческая приёмка не заявляются.
