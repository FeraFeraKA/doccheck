# NRT-107 — таблица и раскрытие строки сверки

[NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck)
сверена 14 ноября 2026 года. База `23acfe55fcfe899ba71a196ef3f386a63e13f109`.
Источник [`2d0c53c`](https://github.com/ananakimov/project-placeholder/tree/2d0c53c04c73526d9ee246df9f6c8909375a3485).

| Файл источника | Перенос |
| --- | --- |
| `src/pages/CheckDetail.tsx` | `ResultTable.tsx` переносит фильтры, поле поиска, строку с раскрытием, список документов и пустое состояние. В `CheckDetail.tsx` остаются выбор, прокрутка и привязка к панели. |
| `src/styles/workspace.css` | `result-table.css` адаптирует стили индикатора, строки и раскрытия к текущим переменным DocCheck. |

Поиск ищет название показателя и имена связанных документов. Enter и
пробел раскрывают строку, Alt+↑/↓ выбирают, раскрывают и фокусируют
расхождение. Суммы и единицы берутся из сохранённого результата. Для
каждого слагаемого отдельно доступны основания суммы, договора,
периода, статьи и идентификации при их наличии. Выбор передаёт текущей
панели ID доказательства. Шапка, вкладки и панель источника ведутся
отдельно. Формулы, данные и действия upstream в runtime не добавлены.

Сверены 25 разрешённых примеров. На текущем срезе прошли 142 Vitest,
21 Playwright, lint, проверка типов и production build. В Chromium
проверены 320, 390, 768 и 1440 px. При раскрытии и выборе C7 ширина
страницы остаётся в пределах viewport. Скриншоты синтетического
примера на 390 и 1440 px сохранены локально. Новый Playwright проверяет
адреса C6/C7, клавиатуру, поиск и сброс. Браузерные проверки используют
готовую синтетику и подмену HTTP в сохранённых сценариях. Рабочий
pipeline и сборка со смежными ветками здесь не проверялись.
