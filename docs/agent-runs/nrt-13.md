# NRT-13 — HTTP-контракт и синтетические ответы

[Задача Linear](https://linear.app/andreiakimov/issue/NRT-13/kontrakt-api-i-moki-dlya-fronta)
прочитана 13 ноября 2026 года. Техническая основа — схема и пример NRT-86,
объединённые в `main`. Предметная приёмка NRT-18 открыта.

- `contracts/doccheck-api.v0.openapi.yaml` описывает загрузку, историю,
  состояния, результат, документы, адреса доказательств и экспорт XLSX.
  Пределы загрузки и правила повторной отправки сформулированы как
  техническое предложение для ревью.
- `contracts/README.md` связывает HTTP-контракт с существующей схемой и
  примером. Синтетический пример остаётся в репозитории для разработки UI
  и тестов. Рабочий API не раздаёт фикстуру.
- `uvx --python 3.12 --from openapi-spec-validator==0.7.2 openapi-spec-validator contracts/doccheck-api.v0.openapi.yaml`
  прошёл. Дополнительно проверены ссылки OpenAPI и соответствие результата
  и записей доказательств из синтетического JSON схемам HTTP-ответов.
- `uv run --frozen --with jsonschema==4.26.0 --project backend python -m pytest backend/tests/test_result_contract.py -q`
  прошёл, 102 теста. `git diff --check` прошёл.

Следующие задачи реализуют маршруты NRT-96, NRT-97 и NRT-36. В этой задаче
согласуется контракт. Приём файлов, обработка, выдача источников и экспорт
в рабочем приложении ещё не проверялись.
