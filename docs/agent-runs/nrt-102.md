# NRT-102 — просмотр источника показателя

[Задача NRT-102](https://linear.app/andreiakimov/issue/NRT-102/frontend-podklyuchit-prosmotr-istochnikov-pokazatelya)
прочитана в Linear 14 ноября 2026 года. Проверяемая база
`240f710169f813631bd7f7ed3354dd3350d99261` содержит NRT-97 и NRT-101.
Исходный документ и фрагмент остаются первичными источниками сводного значения.

## Цель и критерии Linear

- [ ] По выбранному доказательству открываются документ задания и доступный
  адрес. Отсутствующий или неподтверждённый адрес явно обозначается.
- [ ] PDF, изображения, XLSX и DOCX поддерживаются в пределах согласованного
  контракта. Неподдерживаемые возможности обозначены.
- [ ] Ошибки загрузки и отсутствующий документ обработаны. Интерфейс
  формирует маршруты из идентификаторов задания, документа и доказательства.
- [ ] Есть автоматизированная и браузерная проверка связи результата
  с источником. Отдельная проверка результата рабочей обработки зависит
  от фактических адресов NRT-95.

## Реализация

В карточке сохранённой проверки кнопка «Просмотреть источник» открывает
оригинал и адрес из NRT-97 для текущего доказательства. Переключение
показателя или доказательства закрывает просмотр, отменяет устаревший
запрос и освобождает ссылку на загруженные байты. В готовом примере
остаются структурные адреса, запросов к серверу из примера нет.

Для PNG доступен просмотр с рамкой при наличии подтверждённого
`bbox`. Для PDF доступна ссылка на страницу в браузерном просмотрщике.
Строка, ячейка и координаты доступны как подписанный адрес, а рамка
поверх PDF отсутствует. Для XLSX и DOCX показан структурный адрес
и доступно скачивание для офисного приложения. Неизвестный формат
и недоступный фрагмент явно обозначены. Ошибки оригинала и адреса
отображаются отдельно, доступен повтор запроса.

Формат документа берётся из проверенного поля результата. Имя файла
служит для отображения и скачивания. Сверены правила источников,
разрешённый набор кейса и синтетические файлы. Предпросмотр не
выполняет распознавание или сверку.

## Проверки

- Node 26.12.1 и pnpm 12.14.0. Прошли frozen install offline,
  lint, typecheck, build, 112 Vitest, 13 Playwright и `git diff --check`.
  Проверены форматы, ошибки, отсутствие адреса, отмена и освобождение
  object URL. Браузерный тест с подменой API проверяет переключение
  PDF → XLSX, корректную привязку ID и отсутствие запросов до открытия.
- Отдельно проверен настоящий маршрут Chromium → Vite → FastAPI →
  PostgreSQL 18.4 и локальное хранилище. Сохранённый синтетический
  результат валидирован `CheckJob`. Оригиналы PDF и XLSX и их адреса
  получены по HTTP 200. SHA оригиналов из ответов и скачанного PDF
  совпали с сохранёнными файлами. Проверены PDF-страница 1 и XLSX C6.
  Рабочая обработка документов и реальное получение адресов от ML
  в этот прогон не входят.
