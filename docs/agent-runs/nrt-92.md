## Что установлено

PR #8 уже слит человеком в базу; код `doccheck-ml` 0.1.0 доступен.
Пакет обрабатывает готовые наблюдения, проверяет SHA, применяет identity-политику
и возвращает evidence/группы/очередь проверки. Полный разбор форматов, OCR страниц,
КФЗ, финансовая сверка и интеграция в API/worker им не реализованы.

Три P2 из PR #8 подтверждены: смешение даты договора и документа, принятие
обрезанного номера, потеря отрицательного итога. Runtime не исправлялся в рамках
назначения на аудит. Новые тесты утверждают правильное желаемое поведение,
помечены `expectedFailure`; ожидаемые падения не считаются исправлениями.

## Проверки

На Apple M4, arm64, macOS 26.6.2, Python 3.14.4:

1. Установка `pip install --no-deps ./backend/ml_module` в отдельном окружении —
   wheel собран, `doccheck-ml==0.1.0` установлен; ML-зависимости и веса не загружались.
2. Исходный набор `unittest discover -s backend/tests/ml_module -q` — 161 успешный тест.
3. Установленный пакет и итоговый набор — 166 тестов: 161 успешный и 5 ожидаемых
   падений по известным P2, других ошибок нет.
4. `doccheck-ml demo` — 2 records, одна группа одинаковых синтетических байтов,
   `synthetic=true`, оба признака inference/financial reconciliation — false.
5. CLI `process` на синтетическом манифесте: коды 0 (корректный вход),
   1 (существующий выход), 2 (изменённый исходный файл). Прежний выход не перезаписан.
6. Reader без предоставленного каталога весов — `QwenUnavailableError`; это
   проверка отказа, не реальный прогон модели.
7. Полный итоговый diff, допустимые пути, относительные ссылки и `git diff --check`
   проверены до коммита. Самопроверка не заменяет независимое ревью worker-a.

## Ограничения и передача

`ML: no_training`: обучение, дообучение и перезапись весов не выполнялись.
Кандидат модели и его публичная лицензия проверены по текстовой карточке точной
ревизии; разрешённый локальный комплект весов/адаптера не передан. Качество,
лицензия адаптера, peak RAM/VRAM, холодный запуск, GPU/контейнер и сетевая изоляция
остаются непроверенными. Лимит reader 9 GiB не объявляется потреблением памяти.

Синтетические входы воспроизведений доступны в тестах. Локальная копия кандидатов
на Mac worker-b: игнорируемый `data/ml-candidates/NRT-92/audit-cases.json`, источник —
созданные тестовые строки, причина — три подтверждённых P2. Это не holdout и не
независимый эталон; каталог не переносится автоматически на другое устройство.

Следующий шаг: PR в назначенную ночную ветку, In Review + review, ревью worker-a,
Codex Code Review и CI актуального совместного результата. Для runtime-исправлений
нужно отдельное назначение. Аудит не является приёмкой модели; main, merge,
деплой и Done worker-b не выполняет. Сохранённая NRT-89 в другой копии не менялась.
