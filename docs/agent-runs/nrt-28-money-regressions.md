# NRT-28 — регрессия точной суммы в копейках

[NRT-28 в Linear](https://linear.app/andreiakimov/issue/NRT-28/nezavisimye-proverki-deneg-formul-i-otsutstvuyushih-znachenij)
сверена 14 ноября 2026 года. База `a9082d9d8bcfc5421782178fe1022760cf3eb1e9`.

Тест проверяет контракт сохранённого результата с двумя адресными
слагаемыми противоположных знаков. Целые рубли сокращаются, 47 минус 12
копеек дают 35, а 25 минус 35 дают дельту −10 копеек. Ожидания заданы
вручную. Вариант с согласованными между собой нулевой суммой и дельтой
25 копеек отклоняется по сумме слагаемых.

Команда в `backend/`:

```sh
uv run --frozen pytest -q tests/test_money_contract_regression.py tests/test_result_contract.py
```

Прошли 103 теста, Ruff и `git diff --check`. Тест изменяет только копию
синтетического результата в памяти. Знаковые суммы и разницу в рабочем
конвейере предстоит проверить отдельно. Тесты чтения формул и суммы
взносов ведутся в PR #34, отдельного сравнения допущенных значений —
в PR #61. Правила округления и преобразования тысяч рублей в эту проверку
не входят.
