# NRT-95 — источники разных форматов

[Задача NRT-95](https://linear.app/andreiakimov/issue/NRT-95/podklyuchit-ml-adapter-k-worker-i-sohraneniyu-rezultata).
Срез продолжает локальную интеграцию v3.2 с загрузкой файлов из очереди
и адресными результатами. Проверены структуры всех файлов комплекта
`docs/case/examples`, включая отдельное чтение изображения PDF КФЗ.
Сводка ожидаемых результатов и файлы описания комплекта не используются
как вход обработки.

- Поддерживаемые нативные источники DOCX, XLSX и PDF сверяются с
  наблюдениями уже существующих локальных читалок. Для XLSX ведомостей и
  взносов основания суммы включают нативный итог, заголовок шаблона,
  маркированный договор и явно указанный календарный период. Варианты с
  неоднозначными суммами или недостаточными реквизитами требуют проверки.
- PDF и PNG принимаются на стадию извлечения v3.2. Ответ модели из
  изображения без нативного адреса не попадает в денежные слагаемые.
  Файл с таким результатом требует ручной проверки.
- Нативный PDF КФЗ допускается, если текстовые наблюдения однозначно
  связывают договор, период и подписи сумм с исходными адресами. При
  недоступности этих наблюдений возвращается ошибка чтения области
  PDF, а не отдельный результат с подставленными значениями.

Официальная PDF КФЗ представляет собой скан с таблицей за несколько
периодов. Текстовых наблюдений из PDF нет. Текущая модель v3.2 возвращает
кандидатов по фиксированной строке своего бенчмарка, без доказательного
адреса и календарных границ выбранной строки. Для полного прогона нужен
утверждённый локальный провайдер OCR для исходной ориентации страницы.
Он должен вернуть подтверждённую строку и заголовки, договор,
календарные границы выбранного периода из источника и адреса сумм.
Если границы или строка однозначно не определяются, запуск остаётся
заблокированным. PDF хранит конец этапа 30 мая, а пояснение комплекта
описывает период первички до 31 мая. При выборе области из КФЗ суммы
за пределами подтверждённой даты окончания не допускаются.

Команда `uv run --project backend --frozen pytest -q backend/tests/test_v32_adapter.py`
проверяет интеграцию с подменой HTTP Ollama, в том числе XLSX с формулой
и месячным периодом, PNG без доказательного адреса и отклонение растрового
КФЗ без доказуемой области. Живой GPU и браузер этим прогоном не запускались.
