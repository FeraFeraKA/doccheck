# NRT-107 — фильтры чтения документов

[NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck)
сверена на базе `1dcb84280e0234401df310d023aae98aabef0d56`.
Фильтры «Все», «Прочитано» и «Ошибочные» перенесены из
[`CheckDocuments.tsx` на `f52a24d`](https://github.com/ananakimov/project-placeholder/blob/f52a24d106c268397a449b8ad10b10e67e6da932/src/pages/CheckDocuments.tsx).

В DocCheck фильтры используют `parse_status` из существующего контракта.
Исключённый, но прочитанный файл виден в «Прочитано» и сохраняет решение
и причину исключения. В «Ошибочных» видны полная ошибка и частичное
чтение с отдельными подписями. Ожидающие и прежние файлы без состояния
чтения видны в «Все». Отсутствующее поле принимает существующий клиент,
явно некорректное значение отклоняется. На странице «Исключения»
сохраняются фильтры по решениям.

Прошли 146 Vitest, 32 Playwright, lint, проверка типов, сборка и
`git diff --check`. Проверены старый ответ без поля, неверные значения,
прочитанная исключённая копия и реальные различия между состояниями
в синтетических ответах. Браузерные тесты использовали встроенный пример
и подмену HTTP. Порт 55128 освобождён. Рабочий обработчик и OCR не запускались.
