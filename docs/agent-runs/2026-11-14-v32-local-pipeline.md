# Перенос локальной сверки v3.2

Связанный контекст [NRT-92](https://linear.app/andreiakimov/issue/NRT-92/izuchit-gotovyj-ml-modul-i-ego-interfejs).
По просьбе владельца перенесён проверенный конвейер в отдельную ветку для
запуска на другом компьютере. В `bench/e2e_v32_20261114/` включены локальная
команда сверки, зависимости, проверки и манифест ссылок на уже опубликованные
примеры. Правила классификации, идентичности и денежных расчётов перенесены
из локальной v3.2 без правок. В обвязке добавлена поддержка чтения путей
Windows и текстовых файлов UTF-8.

Тесты запускаются командой `python -m unittest discover -s bench/e2e_v32_20261114 -t .`.
Режим запуска, поддерживаемые файлы и выходы описаны в README конвейера.
На другом компьютере требуется подготовить локальную модель с закреплённым
digest и проверить собственное окружение.

Проверка на macOS: 136 тестов, все прошли. Локальный сквозной запуск
синтетического комплекта подтвердил две статьи и общий итог, копия учтена
один раз. Манифест исходного комплекта прошёл сверку хешей всех 23 файлов.
