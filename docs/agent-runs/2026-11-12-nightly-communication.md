# NRT-90: короткий обмен между ночными чатами

- Подготовлены протокол `v2`, порядок чтения и восстановления событий, короткие шаблоны минутного продолжения и обновлённые инструкции участникам.
- На существующей истории NRT-90 проверено чтение Linear MCP: первая страница из трёх, затем страница до 100 записей по курсору вернули 24 разных комментария в порядке от новых к старым. Тестовый `STOP` находился шестым и не входил в первую страницу.
- Пример фильтрации первой страницы из `communication.md` выполнен через доступный `functions.exec`: из трёх записей в вывод попало одно протокольное событие, курсор следующей страницы сохранён. Это не проверка доступности такого исполнения на Mac друга.
- Независимый ревьюер проверил локальный diff: после исправления найденных проблем с поздними событиями, конкурирующими запусками и восстановлением незавершённых действий существенных замечаний не осталось. Ревью не является приёмкой пилота.
- Полное восстановление после задержанной выдачи, новое минутное продолжение, доставку назначений и остановку по обновлённому протоколу на обоих устройствах ещё предстоит испытать. Правила независимого ревью в этой работе не менялись.
