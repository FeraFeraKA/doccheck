# NRT-107 / NRT-99 / NRT-100 / NRT-102 — мастер и просмотр документов

Контекст прочитан в Linear 14.11.2026:
[NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck),
[NRT-99](https://linear.app/andreiakimov/issue/NRT-99/frontend-podklyuchit-zagruzku-dokumentov-i-sozdanie-zadaniya),
[NRT-100](https://linear.app/andreiakimov/issue/NRT-100/frontend-podklyuchit-status-zadaniya-i-istoriyu-zapuskov) и
[NRT-102](https://linear.app/andreiakimov/issue/NRT-102/frontend-podklyuchit-prosmotr-istochnikov-pokazatelya).
База — `569ddabd80a602b947fb1f5055f641892111db48`.

- **Мастер и очередь.** `NewCheck.tsx`, `RunQueue.tsx`, `usePreparedRun.ts`,
  `createRun.ts`: чтение и передача имеют отдельные состояния. Запуск
  доступен после подтверждения загрузки. Активный запуск наблюдается в
  очереди, а готовый открывает результат. Отдельный экран ожидания заменён
  переходом к очереди с идентификатором запуска. Его состояние загружается
  по ID, даже если проверка находится за пределами первой страницы.
  История по-прежнему показывает ошибки сервера.
- **Пакет.** `api.py`, `uploads.py`, миграция `0006_prepared_upload` и OpenAPI:
  подготовленный пакет не виден в истории и не забирается воркером, пока
  пользователь не нажмёт запуск. Повтор запроса запуска возвращает тот же ID.
  Подготовленные пакеты действуют час. После истечения срока они удаляются
  при последующих успешных загрузках, либо при явной отмене пакета.
  «Изменить комплект» создаёт новую сверку с оригиналами выбранных файлов
  и сохраняет прежний результат.
- **Документы.** `SourceWorkspace.tsx`, `OfficeReader.tsx`,
  `DocumentSourcePreview.tsx`, `PdfReader.tsx`: глаз открывает документ с
  начала. Подсвечиваются сохранённые адреса в видимой области. Выбор
  доказательства выделяет нужное место и позволяет вернуться к обзору.
  Выбранная строка КФЗ восстанавливается после перезагрузки. Кнопки
  листания имеют центрированные SVG. Причины в правиле проверки не
  повторяются, отдельное замечание и его адреса доступны в самой строке.
- **Результат и архив.** `ResultHeader.tsx`, `ResultDocuments.tsx`,
  `ResultSummary.tsx`, `ChecksOverview.tsx`: в шапке документов доступно
  изменение комплекта, исключения расположены на той же вкладке, архив
  использует порядок сервера. Между таблицей документов и исключениями
  осталась только нижняя граница таблицы. Кнопки демонстрационных примеров убраны
  из основной навигации, маркировка синтетических результатов сохранена.

Проверены 155 Vitest, 59 Playwright и 14 повторных браузерных тестов
просмотрщика после правки стрелок, lint, typecheck, сборка, OpenAPI, Ruff
и 502 backend-теста с изолированной PostgreSQL. Один backend-тест,
которому нужен администратор выделенного кластера, пропущен. Два живых
синтетических пакета v3.2 прошли браузерный сценарий до выгрузки оригинала.
В Brave проверены загрузка, очередь, первый ряд XLSX, новый результат
при правке комплекта с сохранением прежнего, архив без сортировки и
центровка четырёх стрелок.

При `progress: null` процент обработки не определён. Для второго стенда
нужно развернуть frontend и API одной ревизии, применить `alembic upgrade
head`, проверить новый маршрут загрузки в прокси и сохранить данные
PostgreSQL и хранилище оригиналов. Публичный режим не принимает документы.
