# Публичная документация и локальный запуск

Задача — сделать описание проекта и инструкции запуска понятными внешнему
читателю, сохранив ограничения обработки и правила работы с данными.
Контекст репозитория и окружения: [NRT-6](https://linear.app/andreiakimov/issue/NRT-6/repozitorij-okruzhenie-i-dostupy).

Изменены корневой README, документация frontend, backend и архитектуры;
добавлена инструкция локального запуска обработки на Windows. Входная
страница различает штатный синтетический Compose и отдельный документный
worker с локальной моделью. Имена участников и внутренние регламенты
убраны с главной страницы.

Проверены относительные ссылки и якоря, `git diff --check`, а также
`docker compose config --quiet` для стандартного набора и профиля
`document-worker`. В изолированном окружении прошли 43 теста адаптера и
143 теста v3.2; тесты используют подмены и не подтверждают качество
реального распознавания. Независимое содержательное ревью рабочего diff
замечаний после исправлений не выявило.

Docker Engine при проверке был недоступен. Чистая установка Windows,
контейнерный запуск, реальная модель и полный комплект документов в этой
работе не запускались. Следующий шаг — воспроизвести выбранный сценарий на
релизной версии и проверить его на полном и неполном пакетах.
