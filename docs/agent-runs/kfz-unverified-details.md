# Подпоказатели КФЗ без подтверждения

[Контекст NRT-16](https://linear.app/andreiakimov/issue/NRT-16/inventar-dannyh-i-razbor-otchyota-kfz)
сверен 14 ноября 2026 года. Изменение подготовлено для локального DocCheck с HTTPS-туннелем.

OCR читает трудоёмкость и подколонки внутри 0200 и 0300 по видимым заголовкам и границам таблицы.
Если значение ячейки уверенно прочитано, результат сохраняет значение и адрес на скане.
Для этих подпоказателей пока нет независимых расчётов по источникам. Результат выдаёт
«Не проверено» с пустыми ожидаемым значением и разницей. Рублёвые подколонки содержат
ссылку на сводную статью и исключены из суммарного покрытия. Результаты предыдущих
запусков читаются прежним способом, миграция БД не требуется.

## Проверки

- Ruff и git diff --check.
- 134 теста backend с PostgreSQL, включая автоматический выбор строки, расчёты и XLSX.
  Синтетический скан использует изменённые колонки, период и значения. Проверены подколонки,
  пустая ячейка, координаты источника, рублёвое покрытие и общий корень расхождения.
- 152 теста Vitest, 12 затронутых сценариев Playwright и production-сборка.
- Исходный комплект прогнан после синтетики в изолированной локальной схеме PostgreSQL
  с GPU и LoRA. Подтверждены статусы сводных строк, девять отдельных подпоказателей и XLSX.
  Контрольные данные не используются обработчиком.
