# Сверка статей КФЗ 0400–0700

14 ноября 2026 года. Изолированная ветка от коммита
5057776226cc958f3be4b0d460a8b1d5958933f4. Контекст проверки взят из
[NRT-24](https://linear.app/andreiakimov/issue/NRT-24/algoritm-svyazyvaniya-pokazatel-dokumenty)
и [NRT-29](https://linear.app/andreiakimov/issue/NRT-29/sravnenie-kfz-i-svodnyh-znachenij-po-podtverzhdyonnym-pravilam).
Названия статей сверены с [формами калькуляции ФАС](https://mchs.gov.ru/dokumenty/bazovye-normativnye-pravovye-akty/normativnye-pravovye-akty-ministerstv-i-vedomstv/7892).

- 0400 — подготовка и освоение производства.
- 0500 — специальная технологическая оснастка.
- 0600 — специальное оборудование для научных и экспериментальных работ.
- 0700 — специальные затраты.

Обработчик читает эти статьи в XLSX и сканах КФЗ. Для первички используются
явный код или однозначное назначение с адресом доказательства. Для документов
с общим итогом и несколькими статьями требуется разбивка суммы. Сумма по
доступным источникам и её разница с КФЗ отражаются в результате и XLSX.
При неизвестной полноте официальный статус строки — unverified.

Проверены API загрузки, очередь PostgreSQL, отдельный worker и экспорт XLSX.
Серия на Windows с Tesseract обработала 12 комплектов по 16 файлов.
Правильно распределены 96 слагаемых. Совпали с эталонами 48 сумм КФЗ и
48 сумм первички. Обнаружены 12 совпадений сумм и 36 ожидаемых разниц,
включая положительные и отрицательные разницы в одну копейку. В каждом
комплекте проверены исключение дубликата, другого договора и чужого периода
и ручная проверка четырёх неоднозначных документов. В Windows контрольное
окружение отключало вызов Qwen. OCR и извлечение работали по файлам.

Четыре контрольных комплекта повторены на RTX 2060 с Qwen3.5 и LoRA.
Во всех четырёх сохранена версия модели и адаптера. Проверены 32 слагаемых
и 16 строк сверки. В серии использовались КФЗ в XLSX, скан списка статей и
скан широкой таблицы с отдельной подстатьёй 0401. Пакет с широкой таблицей
повторён после исправления чтения заголовка 0600.

Воспроизведение на отдельном сервере DocCheck с запущенным worker:

    python scripts/check-kfz-articles.py data/articles-check --port <порт> --seed 84008 --count 12

Для генератора нужны ReportLab и шрифт с кириллицей. Эталонные суммы
сравнивает клиент теста после ответа API. На сервер попадают синтетические
входные документы и параметры области сверки.
