# NRT-89 — чтение синтетического пакета на Windows

[NRT-89 в Linear](https://linear.app/andreiakimov/issue/NRT-89/sinteticheskij-komplekt-dokumentov-i-generator-variacij)
прочитана 14 ноября 2026 года. База `3d62cc551c38af73e1917d159ccfd3d210235d34`.

До правки на Windows с CP1251 два из семи тестов завершались ошибкой.
Ячейка A3 и манифест содержали одинаковый договор. Верификатор прочитал
UTF-8-манифест в системной кодировке и исказил кириллицу, поэтому
срабатывала проверка A3. В тесте повреждения PDF проверка останавливалась
на том же месте до чтения изменённого файла. С `PYTHONUTF8=1` до правки
прошли все семь тестов.

Верификатор читает оба JSON в UTF-8, как их записывает генератор. Тест
изменённого ожидания читает и записывает временную копию с той же кодировкой,
сохраняя кириллицу. Генератор, файлы комплекта и ожидаемые значения остались
байт-в-байт прежними.

После правки прошли семь тестов с `PYTHONUTF8=0` и семь с `PYTHONUTF8=1`.
CLI в режиме `PYTHONUTF8=0` подтвердил 23 файла и распределение статусов
2/1/2. `git diff --check` прошёл. Для проверок использовался только
синтетический комплект из репозитория. OCR и ML не запускались.
