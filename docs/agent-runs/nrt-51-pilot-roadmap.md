# NRT-51 — план пилота DocCheck

[NRT-51 в Linear](https://linear.app/andreiakimov/issue/NRT-51/roadmap-i-plan-vnedreniya-10-ballov)
прочитана 14 ноября 2026 года. [План пилота](../pilot-roadmap.md)
описывает работу бухгалтера, критерии допуска и продолжения пилота,
независимую оценку и открытые вопросы вуза.

Состояние прототипа сверено с NRT-43, NRT-71, NRT-94, NRT-108,
документацией кейса и отчётами интеграции. В плане отдельно приведены
локальная проверка PR #46 и облачный прогон, зафиксированный в Linear.
Публичные маршруты `/` и `/checks/synthetic-example` вернули HTTP 200.
Для опубликованного frontend `635ea657` в Brave повторно проверены
главная, перезагрузка примера и переход синтетического задания в
`completed` через `/system-status`. [Протокол NRT-108](https://linear.app/andreiakimov/issue/NRT-108/razvernut-demo-doccheck-na-vercel-i-render)
Были проверены локальные ссылки, ссылки на задачи и `git diff --check`.

Документ предлагает пилот и условия его проведения. Сквозной прогон
`process_package`, оценка на документах вуза и измерение времени
относятся к будущим этапам. Документ передаётся Андрею Акимову на приёмку.
