# Переход на ревью по подписке и версии frontend

- Задача: проверить встроенное Codex Code Review и согласовать используемые проектом и CI версии Node.js/pnpm.
- Изменения: версия Node.js вынесена в `frontend/.node-version`, frontend CI читает Node.js и pnpm из файлов проекта и использует Ubuntu 26.04. По просьбе Николая удалены workflow, промпт, схема и инструкция API-ревью; общие инструкции независимого ревьюера сохранены.
- Проверки: на Node 26.12.1 и pnpm 12.14.0 прошли установка по lockfile, typecheck, 5 unit/компонентных тестов, сборка и браузерный smoke-тест; проверены YAML и ссылки на версии проекта. В PR #3 отправлен `@codex review`.
- Ограничения: репозиторий нового владельца не отображается в текущих настройках Code Review; на запрос ревью пока не было реакции. Предыдущий API-запуск вернул `Quota exceeded`. Изменения CI не опубликованы и на GitHub не запускались.
- Следующий шаг: подключить репозиторий нового владельца к Codex и проверить подписочное ревью на тестовом PR; согласовать, как передавать актуальную задачу Linear.
