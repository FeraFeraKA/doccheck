Запросы оригинала и доказательства используют текущий `sourceApi`. PNG поддерживает рамку после декодирования изображения, масштаб, отключение подсветки и переход к фрагменту. PDF открывается на доступной странице в браузерной вкладке. XLSX и DOCX показывают структурный адрес и скачивают оригинал. В панели показан только подтверждённый контрактом адрес выбранного доказательства. Полный счётчик страниц, другие аннотации, подготовленные upstream-изображения и mock-данные из upstream в реализацию не вошли. Готовый пример DocCheck сохраняет адреса источников без загрузки оригиналов.

Локально проверены Chromium на 390, 768 и 1440 px, исходная панель с её синтетикой и перенесённая панель с собственной PNG-фикстурой. Проверены открытие и закрытие диалога, возврат фокуса, смена источника после закрытия, адрес PDF и скачивание XLSX. Снимки сделаны вне репозитория. Рабочие документы не использовались.
