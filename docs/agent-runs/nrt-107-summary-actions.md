# NRT-107 — расположение выгрузки XLSX

Сверен [`CheckConclusion.tsx` на `511584a`](https://github.com/ananakimov/project-placeholder/blob/511584a4e0d1d25a161c9310a0afc4c5896f3a60/src/pages/CheckConclusion.tsx).
База DocCheck `163929e4dda88f2ffc0328ac90a416eecb69f3d8`.

Верхний блок «Результата» показывает вывод и данные сверки. Выгрузка
сохранённой проверки доступна в шапке «Документов» и по прежнему
прямому адресу `/checks/:id/conclusion`. Обе точки используют один
существующий компонент и API сохранённого результата. Готовый
синтетический пример открывается без кнопки выгрузки. README, сценарии
и инструкция для демо указывают новое расположение.

Прошли 146 Vitest, 34 Playwright, lint, проверка типов, сборка и
`git diff --check`. Браузерные тесты проверили запрос выгрузки для
точного ID на обеих страницах, отказ и повтор, отсутствие кнопки и
запросов в готовом примере. Транспорт XLSX был подменён. Отдельный
backend-тест подтвердил генерацию и чтение workbook с денежными
строками и текстовыми ячейками; PostgreSQL не запускался. Порт 55128
освобождён. Полный сквозной документный прогон не выполнялся.
