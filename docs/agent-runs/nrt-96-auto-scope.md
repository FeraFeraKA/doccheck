# NRT-96 — приём пакета до определения области

[NRT-96](https://linear.app/andreiakimov/issue/NRT-96/api-prinyat-dokumenty-i-sozdat-zadanie-proverki)
и [NRT-13](https://linear.app/andreiakimov/issue/NRT-13/kontrakt-api-i-moki-dlya-fronta)
прочитаны 13 ноября 2026 года, включая решение Николая о передаче КФЗ и
первичных документов без ручного заполнения договора, периода и строки.
Изначальная база `208fdf7df8387cb5b5127ec0ac8f05c41527c7bf`.

`POST /api/v0/runs` принимает `report` и `documents` с `Idempotency-Key`.
Старый запрос с номером договора, обеими датами и адресом строки КФЗ
проверяется по прежним правилам. Частично переданные параметры получают
`422`. Поля, файлы и правила повторов описаны в OpenAPI. Автоматический
и явный режимы с одним ключом конфликтуют. Формула хеша старых запросов
сохранена.

При отсутствии явной области `runs.scope` хранит пустой объект. Схема БД,
данные существующих записей и результат версии 1 сохраняют прежний формат.
Worker передаёт адаптеру `scope=None`, а `report_document_id` получает из
роли КФЗ в манифесте. Для готового результата проверяются ID запуска,
ID и хеши документов, соответствие загруженной КФЗ и совпадение явно
заданной области. Выведенная адаптером область хранится в `result.scope`.
Откат к прежнему worker требует предварительно обработать или отдельно
удержать новые задания без области, поскольку он ожидает явную область.

## Проверки

- На отдельной PostgreSQL 18.4 прошли 162 backend-теста, включая
  конкурентный повтор файловой загрузки, конфликт двух режимов запроса,
  сохранение старого хеша, отказ при частичной области, проверку готового
  синтетического результата через GET, отказ при подмене КФЗ, хеша или явно
  заданной области. Предупреждение Starlette TestClient о `httpx` сохраняется.
- `openapi-spec-validator` подтвердил валидность OpenAPI. Отдельная проверка
  Draft 2020-12 приняла оба полных варианта и отклонила частичные.
- Ruff и `git diff --check` прошли. Временная БД остановлена и удалена.

После ревью worker также сверяет известные форматы результата с манифестом.
Модель результата проверяет адреса относительно этих форматов. Это исключает
адрес XLSX для загруженного PDF с теми же ID и SHA-256. `format=null` для
непрочитанного источника остаётся допустим при соблюдении контракта результата.
Повторный прогон загрузки, worker и GET на PostgreSQL 18.4 закрыл оба сценария,
всего 58 тестов.

Для незавершённого определения области адаптер может вернуть `failed` без
результата. Политика содержательной диагностики зависит от адаптера. Реальные
ML, OCR и сверка не запускались. Подключение извлечения относится к NRT-95.
Один `CheckResult` версии 1 хранит одну область. Представление нескольких
областей в общем итоге и строках одного запуска требует отдельного
изменения контракта и поддержки в обработчике и интерфейсе.
