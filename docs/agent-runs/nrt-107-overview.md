История получает текущую страницу из существующего API. Для этой страницы
показываются фактические счётчики состояний задания. Число документов,
покрытие и финансовый вывод в контракте истории отсутствуют. Поля
сохраняют место в композиции и показывают прочерк. Завершённость задания
не означает подтверждение сумм. Сортировка по дате сохраняет порядок API,
поиск и сортировка по названию работают по видимой странице. Указатель
следующей страницы передаётся непрозрачным параметром. Синтетическая
сверка остаётся отдельным явно подписанным примером. Публичный режим
показывает пример без запроса рабочей истории.

В Chromium сравнили обе версии на 1440×1000 и 390×844. Заголовок
сохранил размеры 28 и 26 px. Четыре карточки и таблица на широкой
странице переходят в сетку 2×2 и компактные строки на мобильной.
Горизонтального выхода за viewport нет. Высота строк меняется из-за
отсутствия договоров, периодов и вычисленных выводов в истории DocCheck.
Боковая панель и мастер относятся к соседней части переноса.

Прошли frozen install, lint, typecheck, build, 141 Vitest и diff check.
На отдельном Vite порту 55110 Chromium проверил фильтр, поиск, сброс
и кодирование указателя страницы на обеих ширинах. Этот прогон
использует синтетический ответ истории. Публикация не выполнялась.
