# NRT-36 — выгрузка результата в XLSX

[NRT-36](https://linear.app/andreiakimov/issue/NRT-36/eksport-xlsx-json-html-i-pdf-posle-vypolneniya-vseh-zadach),
[NRT-35](https://linear.app/andreiakimov/issue/NRT-35/format-nahodki-i-generator-zaklyucheniya)
и [NRT-19](https://linear.app/andreiakimov/issue/NRT-19/izvlekateli-pdf-s-tekstom-docx-xlsx-bez-ocr)
прочитаны 14 ноября 2026 года. База `46105e821fbee79a1a600d601cd5cb790d52f725`.

`GET /api/v0/runs/{run_id}/exports/xlsx` использует тот же валидированный
сохранённый `CheckResult`, что и `/findings`. Контрактные ответы 404 и 409
сохранены. Имя файла строится из UUID запуска, HTTP-кэширование отключено.
Книга содержит итог, суммы и статусы, частично подтверждённую сумму,
полноту, причины, адреса доказательств и ошибки файлов. Денежные значения
сохраняются текстом с исходной точностью. `null` соответствует пустой
ячейке. Текст не исполняется как формула и не становится гиперссылкой.
Символы, недопустимые в XML, записываются видимыми escape-последовательностями.
Если данные превышают предел формата, клиент получает `503` с безопасным
сообщением. Генерация использует закреплённый `openpyxl==3.1.5`; существующие
зависимости не обновлялись. NRT-19 читает XLSX через XML и этот код не использует.

## Проверки

- На PostgreSQL 18.4 прошли 162 backend-теста. Проверены XLSX по HTTP для
  `completed` и `completed_with_issues`, 404, 409 для ожидающего, выполняемого
  и ошибочного запуска. Открытие выгруженных байтов подтвердило статус,
  адреса, пустые ячейки, десятичную строку длиннее точности числа Excel и
  буквальные ячейки с формулоподобным текстом. Сохраняется прежнее
  предупреждение Starlette TestClient о `httpx`.
- Прошли `uv lock --check`, Ruff, проверка OpenAPI и `git diff --check`.
- Изучен состав разрешённых примеров, включая КФЗ, README и форматы адресов.
  Для тестов экспорта использовались только синтетические данные.

После ревью первичные замечания перенесены в отдельный лист с ID и ссылками
на доказательства и ошибки файлов. Лист «Документы» показывает ID каждой
ошибки. Тест восстановления связи по XLSX проверяет `row-b → issue-b →
scan-read-error` и переход от первичного замечания к ID доказательств.

Книга отражает только сохранённые данные. Правила находок, гипотезы и
заключение добавляет NRT-35. Подключение скачивания в интерфейсе остаётся
следующим шагом. Отдельный промежуточный свод, PDF, HTML и JSON не входят
в текущий объём. Проверка файла выполнена программным чтением XLSX, без
открытия в настольном Excel.
