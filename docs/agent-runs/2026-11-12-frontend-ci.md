# Правила версий и базовый CI frontend

- Задача: закрепить проверку версий библиотек и диагностики перед изменениями, подготовить базовый GitHub Actions для frontend.
- Файлы: `frontend/AGENTS.md`, `frontend/README.md`, `.github/workflows/frontend.yml` и этот отчёт.
- Проверки: локально на Windows прошли `pnpm install --frozen-lockfile`, typecheck, 5 unit/компонентных тестов, сборка и 1 браузерный smoke-тест. YAML разобран, проверены события и команды; `git diff --check` без ошибок.
- Ограничения: запуск в GitHub Actions не проверен до публикации. Линтер и диагностика конкретной IDE не настроены. Backend, OCR и полноценная интеграция в этот workflow не входят.
- Следующий шаг: проверить первый запуск Actions после публикации, затем расширять CI по мере реализации соответствующих задач.
