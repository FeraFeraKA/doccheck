# NRT-53 — технический сценарий демо

[NRT-53](https://linear.app/andreiakimov/issue/NRT-53/pitch-na-3-minuty-i-zhivoe-demo)
сверена 14 ноября 2026 года на базе `635ea65792d001dacdf3ed28ab397302961be7ec`.
Подготовлен [сценарий выступления](../demo-runbook.md) для Андрея
со ссылками на NRT-108, NRT-48, NRT-51 и исторический Compose CI.

Установка из прогретого кэша и сборка прошли с pnpm 12.14.0. Chromium
открыл локальный `/checks/synthetic-example` и после перезагрузки показал
150,50, 120,50 и 30,00. Проверочный сервер остановлен. Публичные
`/checks/synthetic-example` и `/health` ответили HTTP 200, а запрос к
главной из этой среды превысил тайм-аут. Облачный цикл описан по
зафиксированному прогону NRT-108. `git diff --check` прошёл.

Репетиция, запись, замеры качества и скорости, а также проверка
`process_package` остаются отдельными шагами.

После обновления на `6e05af205c713636e6c4a2e723dfac4a10ac24c2` сверены маршрут
`/system-status` в приложении и правиле Vercel, название кнопки и показ ID.
Предпоказовая проверка версии и ID добавлена в инструкцию. Повторный полный
облачный цикл на этом шаге не выполнялся.
