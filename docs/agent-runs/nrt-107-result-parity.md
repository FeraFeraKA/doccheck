# NRT-107 — перенос экрана сверки

[Задача NRT-107](https://linear.app/andreiakimov/issue/NRT-107) и
[исходник Андрея](https://github.com/ananakimov/project-placeholder/tree/2d0c53c04c73526d9ee246df9f6c8909375a3485)
проверены 14 ноября 2026 года. База PR — `c2784d0bfb50df50a1a1f45fe7aa3f6314a22228`.

| Часть исходника | Компоненты DocCheck |
| --- | --- |
| `CheckHeader.tsx` и начало `CheckDetail.tsx` | `ResultHeader.tsx`, `ResultSummary.tsx`, две вкладки, вывод, покрытие и найденные проблемы |
| Таблица и раскрытие строк в `CheckDetail.tsx` | `ResultTable.tsx`, поиск, фильтры, раскрытие, клавиатурная навигация и переход из замечания к показателю |
| `SidePanel.tsx`, `SourceViewer.tsx` и правый Sheet | `SourceDrawer.tsx`, `DocumentSourcePreview.tsx`, открытие доказательства из слагаемого и возврат к таблице |

Таблица занимает всю доступную ширину. Слагаемые открывают сохранённое
доказательство по ID. Видимый доступ к исключениям и прежние прямые маршруты
сохранены. XLSX доступен для сохранённой проверки. Покрытие показывается
по строкам. Номер КФЗ, покрытие по сумме и подпись требуют данных или действий,
которых текущий контракт не предоставляет. В готовом примере доступны адреса.
Для сохранённого источника PNG показывает рамку, PDF открывает страницу,
XLSX и DOCX показывают структурный адрес и оригинал. Внешний комплект и его
изображения в DocCheck не входят.

На общей ветке прошли lint, typecheck, 142 Vitest, 23 Playwright,
рабочая и публичная сборки, `git diff --check`. Chromium сравнил общий
вид референса и DocCheck на 390 и 1440 px с разными синтетическими данными.
Панель источника отдельно сравнивалась на 390, 768 и 1440 px. Проверки источника
выполнены на синтетическом HTTP-ответе.
