# NRT-48 — проверка воспроизводимости сценариев

[NRT-48 в Linear](https://linear.app/andreiakimov/issue/NRT-48/dva-use-case-s-vhodom-i-ozhidaemym-rezultatom)
прочитана 14 ноября 2026 года. База `f2781e1acd818a35593a1f4d8545a42cd9cb1ed2`.
[Два сценария](../case/use-cases.md) используют опубликованный пакет NRT-89
и его вариант с обрезанным PDF.

Проверены SHA-256 всех 23 входов, состав документов и арифметика сценариев.
Команда из инструкции успешно отработала в изолированной копии
`cbb69dc25aeae910ffd08439ca6b71271669b335` PR #58 и установила
`openpyxl==3.1.5` и `et-xmlfile==2.0.0`. Сверены SHA-256 исходника и
производного из манифеста. Обрезанный файл имеет заголовок PDF и не
содержит завершающий маркер. Локальные ссылки и git diff прошли проверку.

Значения в сценариях служат ожидаемыми результатами на синтетике.
Для продуктовой приёмки нужны рабочий адаптер, сквозная сверка
и подтверждение Андрея. Случай меньшего факта при совпадении с КФЗ
ожидает отдельный разрешённый вход с планом. OCR и ML не запускались.
