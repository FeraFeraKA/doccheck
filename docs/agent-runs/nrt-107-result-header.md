Сводка показывает вывод и первичные замечания из результата, включая
отдельный случай без показателей. Цвет и короткая метка основаны на
счётчиках контракта. Договор и период берутся из области проверки.
Заголовок использует доступное имя проверки. Контракт этого среза не
предоставляет номер КФЗ или денежное покрытие; подпись и дополнительные
форматы экспорта не переносились.

Действие XLSX доступно в сводке сохранённого результата. Прямой маршрут
`/conclusion` продолжает открывать сводку. В «Документах» и карточке
замечаний есть переход к «Исключениям». Связывание карточек замечаний с
раскрытием строк относится к стыковке с новой таблицей.

Chromium на 390 и 1440 px сопоставил шапку, вкладки, вывод и карточки
с опубликованным явно синтетическим примером `g`. На 390 px ширина
референса 401 px, локальная страница укладывается в 390 px. Снимки
оставлены вне репозитория. Точный коммит публикации Pages не выводился
из браузерного прогона.

Прошли lint, typecheck, сборка, 142 Vitest, 20 Playwright и
`git diff --check`. Сетевые сценарии использовали синтетические HTTP-ответы.
