# NRT-107 — пояснение в строке результата

[NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck) и
[изменение интерфейса Андрея](https://github.com/ananakimov/project-placeholder/compare/ed8c2f159fbc207c177aaf950649d456553ca4c4...9b8ca16ea07c29cec24f700689ff04e160fd5e73)
проверены 14.11.2026. Из ячейки «Пояснение» убрана вторая кнопка раскрытия.
Название строки раскрывает расчёт, причины, слагаемые и адреса источников.
Доступ к оригиналу КФЗ по сумме в таблице сохраняется.

Изменены ResultTable, относящийся CSS и браузерная проверка раскрытия и
выбора адресов с клавиатуры. Прошли проверки типов, lint, два сценария
Playwright и `git diff --check`. Проверка использует синтетический результат.
Деплой не выполнялся.

## Постановка и критерии из Linear

Задача прочитана 14 ноября 2026. Цель — поддерживать соответствие
интерфейса DocCheck проекту Андрея и подключать перенесённую вёрстку к
рабочей бизнес-логике DocCheck.

- Примерно каждые 45 минут проверять `main` источника и сверять коммиты
  с последней проверенной версией и открытыми PR DocCheck.
- Переносить компоненты и разметку по файлам. Адаптировать Tailwind-классы,
  стили, импорты, props и действия под React Router, Vite, pnpm и текущие
  контракты DocCheck. Сохранять структуру и компоновку экранов.
- Сохранять путь бухгалтера, интеграцию API, адресные доказательства и
  явную маркировку синтетики.
- Переносить применимые изменения отдельным PR с проверками, ссылкой на
  диапазон и соответствием исходных и перенесённых файлов. Прикладывать
  результат браузерной сверки. Спорные изменения передавать владельцу
  с зафиксированной причиной пропуска.
- Для основного переноса сначала идут навигация и мастер, таблица и
  панель источника могут идти параллельно. Эти экраны уже перенесены в
  #101. Текущий PR переносит только последующую правку пояснения.

Входной `IndicatorExplanation.tsx` соответствует ячейке пояснения в
`ResultTable.tsx`. В ней остаётся краткий текст, а подробности
раскрываются по названию показателя. Подтверждение через Chromium
зафиксировано в браузерном тесте под синтетическим сценарием.
