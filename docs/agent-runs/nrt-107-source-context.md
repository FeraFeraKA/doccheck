# NRT-107 — сведения об источнике в правой панели

[NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck)
· База `9ab00362e4658f666d51cb0a2e2170fd2c4dd9dd`.

Шапка с показателем, вкладки «Источник» и «Правило проверки» и выбор
доказательства перенесены из upstream `SidePanel.tsx` в
`SourceContext.tsx` и `CheckDetail.tsx`. Используются суммы, статус,
полнота, формула и ID правила из существующего результата.
[Исходный компонент](https://github.com/ananakimov/project-placeholder/blob/79bb0b17836b93e464983a23ed3ac4b272923242/src/components/check/SidePanel.tsx)

Переходы между доказательствами сохраняют размер панели. Выбор другого
адреса того же файла запрашивает фрагмент, сохраняя оригинал и масштаб.
Оригинал загружается заново при смене документа. Готовый синтетический
пример по-прежнему показывает доступные адреса. На низком экране суммы
видны во вкладке правила, чтобы освободить место документу.

Chromium на 390 и 768 px проверяет клавиатурные вкладки, два адреса PNG,
смену документа, сохранение масштаба и отсутствие фонового Alt+↓.
Использованы разрешённый синтетический PNG и синтетические HTTP-ответы.
Прошли lint, typecheck, сборка, 142 Vitest, 33 Playwright и
`git diff --check`.
