# NRT-14 — интерактивный демо-интерфейс

Реализован согласованный экран и боковая панель на React/TypeScript/Vite/Tailwind. PDF/PNG и координаты созданы из синтетических данных; оригиналы и эталоны не использовались.

## Проверено

- `npm run typecheck`, `npm test` (2 теста), `npm run build:demo`, обычный `npm run build`, `git diff --check` — успешно.
- В обычной сборке нет DemoApp, PDF/PNG доказательств и строк демо-фикстуры.
- Brave через расширение: обе темы и сохранение после reload; выбор статьи меняет формулу/источник; фильтр unverified показывает null и отсутствие источника; боковая панель и демо-запуск до завершения; вкладки переключаются стрелками; масштаб 100→125%.
- Viewport 390 px: одноколоночная сетка; страница не шире viewport, таблица прокручивается отдельно.
- Консоль Brave: ошибок и предупреждений при проверке не получено.
- JSON-экспорт вызван из UI, приложение подтвердило подготовку. Ожидание download в расширении завершилось таймаутом; скачанный файл через браузер не проверен. Отдельная проверка печати HTML не выполнена.

Исправлены подсветка заголовочной ячейки строки, выравнивание статьи, клавиатура вкладок и начальный размер превью.

## Ограничения

История хранится в памяти страницы, очередь имитируется таймерами. Панель использует фиксированный комплект без пользовательской загрузки. Экспорт presentation-only не является CheckResult.

Нет реального API, OCR/worker, просмотра произвольных многостраничных PDF, XLSX/DOCX и сетевых ошибок/retry. NRT-8/13/30/31/36/43/49 не закрываются этим демо. Продолжение описано в frontend/README.md.

Ветка nrt-14-reconciliation-ui основана на nrt-7-environment; PR frontend использует эту базу до интеграции NRT-7.
