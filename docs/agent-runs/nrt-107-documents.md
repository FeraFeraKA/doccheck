# NRT-107 — документы и исключения результата

[NRT-107](https://linear.app/andreiakimov/issue/NRT-107/sinhronizirovat-izmeneniya-interfejsa-andreya-s-doccheck)
прочитана 14 ноября 2026 года. База `2bb0a7051af17a86a0de30b37c64be404ceadf81` PR #71.
Источник [`2d0c53c`](https://github.com/ananakimov/project-placeholder/tree/2d0c53c04c73526d9ee246df9f6c8909375a3485).

- `src/pages/CheckDocuments.tsx` → `ResultDocuments.tsx`. Перенесены
  фильтры со счётчиками, таблица, значки файлов и открытие документа.
- `src/components/check/ExcludedDocs.tsx` → представление тех же
  документов без включённых записей. Отдельно видны исключения, ошибки
  чтения и случаи, требующие проверки. Повторяющийся текст причины
  отображается один раз, а связи ведут к конкретным показателям.
- `CheckDetail.tsx` подключает представления к существующим маршрутам.
  Ссылка из документа раскрывает показатель этого же запуска по его ID.
  При отсутствии подходящего ID открывается обычная таблица.

Панель показывает доступные адреса синтетического примера без HTTP.
Для сохранённого запуска она использует существующий API оригиналов и
доказательств. При отсутствии адреса запрашивается только оригинал.
Номер, дата, количество страниц и денежное влияние остаются за рамками
этого представления. Контракты API и данные не менялись.

Сверены 25 разрешённых файлов комплекта. Прошли 142 Vitest, 25 Playwright,
lint, проверка типов, сборка и `git diff --check`. На 390 px проверены
фильтры, клавиатура, C7, фокус после Escape, ссылка после перезагрузки и
отсутствие API у готового примера. На 1440 px с подменой HTTP проверен
отказ оригинала без запроса фрагмента. В Chromium на 320, 390, 768 и
1440 px обе страницы помещаются в viewport, таблица может прокручиваться
внутри своей области. Скриншоты синтетики сохранены локально в
`data/screens/`. Рабочий pipeline в этих проверках не запускался.
