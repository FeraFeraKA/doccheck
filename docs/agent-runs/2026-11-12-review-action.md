# Подготовка AI-ревью в GitHub Actions

- Задача: подготовить пробный независимый ревьюер через Codex Action и API-ключ по запросу Николая.
- Файлы: `.github/workflows/neuro-review.yml`, `.github/codex/review-prompt.md`, `.github/codex/review-schema.json`, `AGENTS.md`, документация ревьюера и этот отчёт.
- Проверки: YAML разобран, JSON Schema проверена, права и профиль ревьюера сверены. Локально с подставными ответами GitHub, Linear и модели проверены идентификация задачи, неоднозначный ID, запрет fork, получение задачи, изоляция ключа, ошибки GraphQL и HTTP, неверный проект, отсутствие ключа, pass, замечания, неверный ответ, ошибочный запуск и отклонение устаревшего результата. `git diff --check` прошёл.
- Изменение по запросу Николая: workflow получает описание задачи непосредственно из Linear по read-only ключу; содержимое отправляется ревьюеру, а ключ ему не передаётся.
- Ограничения: ключи не запрашивались и в GitHub не размещались; реальные вызовы Linear/OpenAI и запуск workflow не выполнены. Комментарии, приложения и связанные задачи Linear автоматически не загружаются; проверка PR из fork не поддерживается. Отдельный автоматический агент-исправитель и политика защиты ветки не настроены.
- Следующий шаг: после публикации и восстановления GitHub Actions добавить два секрета через интерфейс GitHub и проверить на тестовом PR без закрытых данных.
