Репозиторий указан пользователем: `VCyberPunk2077/doccheck`. База: `4da84d8485945413beff156265c3975b5fad6c7c`. Ветка: `nrt-89-synthetic-package`.

Добавлены `research/synthetic-package/` (генератор, верификатор и тесты) и `docs/synthetic/nrt-89/` (КФЗ и 22 подтверждающих файла, список входов, отдельные ожидания и README). Семь ситуаций NRT-89 представлены в одном комплекте. Все денежные расчеты модели выполняются Decimal/целыми копейками. Файлы явно помечены синтетическими. Это дополнение для локальной приемки, не результат работы приложения.

Оригинальная папка исключена из checkout; ее содержимое и книга ответов не открывались. В генераторе нет чтения локального стенда, исходного архива или документов организаторов. Существующий локальный корпус оценен по коду генератора и синтетической сводке; бинарные файлы из него не копировались.

## Выполненные проверки

- `python -m unittest discover -s research/synthetic-package/tests -v`: 7 тестов пройдены, включая измененный PDF, лишний файл с ответами, неверную эталонную сумму, исключение дубля/периода/договора и равенство частичной суммы.
- `python research/synthetic-package/verify.py docs/synthetic/nrt-89`: 23 файла, 2 verified, 1 discrepancy, 2 unverified. Проверены хеши, форматы, значения нативных документов, формулы и кэши XLSX, суммы и граница входов.
- Полная генерация с seeds 890041 и 890042 и проверка обоих экспортов выполнены. Повторный 890041 воспроизводит манифест фактов и ожиданий. Данные/таблицы XLSX совпадают; идентификаторы OOXML relationships могут менять бинарные хеши.
- PDF отрендерены; просмотрены все страницы PDF/PNG, оба DOCX через `render_docx.py` и все листы XLSX. Превью Artifact Tool не форматирует числовые даты; формат `dd.mm.yyyy` в сохраненном XLSX проверен через XML и дополнительный экспорт LibreOffice.
- `git diff --check`: без ошибок.

Проверки выполнялись на Python 3.12.14, Node 24.22.1 и Artifact Tool 2.8.148. Проверка генератора не доказывает работоспособность OCR/продуктового pipeline; они здесь не запускались.

## Незакрытые критерии и передача

1. Формы созданы заново и упрощены. **Точное расположение полей как в оригинале не подтверждено.** Андрей должен локально сравнить структуру и передать необходимые изменения без оригинальных значений. Отсутствие совпадений существенных реквизитов и сумм также требует его проверки.
2. Ожидаемые статусы заданы при проектировании набора; их предметную корректность принимает Андрей. Это публичная регрессия, не независимый holdout и не общий API-контракт.
3. Генерация XLSX требует Artifact Tool из среды Codex; без него доступно использование/проверка готового набора. Перенос на полностью общедоступные зависимости не заявляется.
4. По NRT-89 удаление `docs/case/examples/` и переключение общих ссылок выполняет Николай отдельным PR после принятия комплекта. В этой ветке оригиналы и общие инструкции не меняются.
