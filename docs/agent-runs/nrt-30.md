прочитана в Linear 14 ноября 2026 года. Проверена база
`9507d476df425c3fe85316c3db67de715bc91790` после слияния #36 и #38.

рабочего адаптера относится к NRT-95, сквозная проверка с интерфейсом —
к NRT-43, предметная приёмка README — к NRT-46.

Проверены маршруты, поведение повтора, поддерживаемые форматы и локальные
ссылки по текущему дереву. `git diff --check` прошёл.
