# NRT-33 — локальный подсчёт показателей сверки

[NRT-33](https://linear.app/andreiakimov/issue/NRT-33/nezavisimyj-etalon-mutacii-i-metriki-pokrytiya)
сверена 14 ноября 2026 года. База `0064a3aead9d59fb9652652b3da935974a0ede90`.
[Инструмент и определения](../../research/reconciliation-evaluation/README.md)
описывают отдельно подаваемые ожидания и наблюдения. Сводка содержит
числители, знаменатели, матрицу статусов и пропуски без идентификаторов.

Четыре синтетических unittest проверили расчёт вручную заданных метрик,
нулевые знаменатели и воздержание, ошибки объединения и пересечение групп,
успех и отказ CLI. Ruff и git diff прошли. Никакие закрытые данные
не использовались. #35 сопоставляет сценарии с покрытием тестами.
Этот срез измеряет статусы целевых строк отдельного набора.

Андрей подтверждает определения метрик и происхождение групп,
размечает закрытые варианты и проводит независимую оценку. Реальное
качество, рабочий pipeline и охват мутаций здесь не оценивались.
