Постановка сверена в Linear 14.11.2026. Согласованные изменения интерфейса
Андрея переносятся отдельными PR с указанным диапазоном исходных коммитов
и браузерными проверками. Критерии сохраняют React Router, Vite и pnpm,
единый путь бухгалтера, API загрузки и ограничение публичной загрузки,
адресные доказательства и явную маркировку синтетики. Этот срез проверяет
постоянную навигацию и доступ к «Проверке системы» на мобильной,
планшетной и десктопной ширине. Сверка и источники пересекаются с
[#82](https://github.com/VCyberPunk2077/doccheck/pull/82), очередь и обзор —
с [#83](https://github.com/VCyberPunk2077/doccheck/pull/83).

Навигация из `src/components/layout/Sidebar.tsx` и правила из
`src/styles/workspace.css` перенесены в `Sidebar.tsx` и
`accountant-workspace.css`. Ссылки видны постоянно. До 700 px меню
занимает верхнюю часть страницы, при 701–1250 px панель занимает 210 px,
на более широких экранах — 240 px. Пункт «Проверка системы» сохранён.
Архив остаётся частью отдельного жизненного цикла проверок.

Chromium проверил 320, 700, 701, 768, 1250, 1251 и 1650 px, геометрию
панели, доступность ссылок и переход с клавиатуры. Проверка использовала
синтетические ответы HTTP. Прошли lint, typecheck, сборка, 146 Vitest,
44 Playwright и `git diff --check`.

По [замечанию #87](https://github.com/VCyberPunk2077/doccheck/pull/87#issuecomment-6873541419)
фиксированная панель прокручивается вертикально. При 768×200 Chromium
проверил, что Tab прокручивает именно панель и делает ссылку «Проверка
системы» полностью видимой, а клик открывает нужную страницу. Мобильная
навигация остаётся в потоке страницы. Повторно прошли lint, typecheck,
сборка, 146 Vitest, 45 Playwright и `git diff --check`.
