# NRT-108. Локальная сверка без галочек

## Изменения

- Форма загрузки передаёт КФЗ и первичные документы сразу. Воркер читает скан и определяет договор, период, этап и страницу по данным комплекта. Если выбор неоднозначен, строку можно уточнить из карточки проверки.
- Суммы сверяются по загруженным документам. Отсутствие первички по статье отражается как расхождение. Нечитаемые документы и неоднозначные суммы сохраняют статус «Не подтверждено».
- Временное пользование измерительным оборудованием для выполнения этапа или проекта учитывается по 0800 при наличии обоснования в документе. Результат сохраняет ссылку на доказательство.
- В `backend/README.md` описан запуск отдельного воркера `--v32` с Tesseract, Qwen и LoRA под Linux или WSL2. Веса и адаптер устанавливаются из разрешённых артефактов.

## Проверки

- Backend. Ruff, проверка формата и схема OpenAPI прошли. Pytest показал 688 успешных тестов, один пропуск, пять ожидаемых падений и 166 успешных подтестов. Отдельный набор ML прошёл 166 сценариев с пятью ожидаемыми падениями.
- Frontend. Oxlint, 152 теста Vitest и сборка Vite прошли.
- Синтетические сценарии проверяют выбор строки скана, отсутствие первички, ошибки чтения и отнесение аренды по её назначению.
- Отдельный локальный прогон этой ветки с RTX 2060 и LoRA прошёл через API, PostgreSQL и воркер. На разрешённом комплекте подтвердились три статьи, одно расхождение по 0800 отразилось в статье и итоговой строке. Выгрузка XLSX прошла.

Для командной приёмки требуется запуск с доступными весами Qwen и LoRA. Тесты классификации, договора API и фронтенда можно запускать без GPU.
