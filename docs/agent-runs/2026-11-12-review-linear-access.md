# Проверка доступа ревьюера к задаче Linear

- Задача: по просьбе Николая уточнить в правилах ревью обязанность получать задачу по номеру из PR и сообщать об отсутствии доступа.
- Файлы: корневой `AGENTS.md`, `docs/agents/reviewer.md` и этот отчёт.
- Проверки: `git diff --check`; реальное поведение встроенного Codex Code Review на тестовом PR проверяется отдельно.
- Ограничения: инструкции не предоставляют доступ к Linear автоматически и не гарантируют, что встроенное ревью опубликует замечание P0; успешный запрос к Linear пока не подтверждён.
- Следующий шаг: запросить ревью на тестовом PR и проверить, получил ли агент задачу или явно сообщил о блокировке.
