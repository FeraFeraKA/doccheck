# Docker Compose с NVIDIA GPU

Добавлены конфигурация `compose.gpu.yaml`, образ документного worker,
подготовка и проверка модели, передача ошибки модели в API и
[инструкция запуска](../docker.md). Базовая конфигурация и миграции сохранены.

Проверены импорт v3.2 в Linux-образе, состав образа, базовый синтетический
Compose и тесты backend и v3.2 с PostgreSQL. Через интерфейс проверены
подготовка пакета, очередь, выполнение локальной моделью на NVIDIA GPU,
суммы из первички, XLSX и сохранение результата и оригиналов после
перезапуска. Проверена ошибка задания при остановке Ollama.

Исходная растровая КФЗ дошла до запроса к модели. Адаптер остановил
сверку на подтверждении области и денежных значений. Для этого сценария
нужны проверяемые адреса строки и ячеек и подтверждённый артефакт модели
для альтернативного адаптера. Детали проверок приведены в PR.
