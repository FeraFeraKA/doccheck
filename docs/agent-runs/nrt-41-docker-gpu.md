# Docker Compose с NVIDIA

Добавлены образ документного worker, сервис подготовки закреплённой базы
Qwen MLX, подключение LoRA для чтения и ожидание готовности worker.
[Инструкция запуска](../docker.md) описывает оба источника базового снимка
и расположение файлов адаптера.

Проверены доступ к GPU из Linux-контейнера, сборка API, интерфейса и
сервиса подготовки, существующие миграции PostgreSQL, конфигурация Compose
и отказ от подменённых весов. Тесты backend, интерфейса и контракта
проверяют интеграцию. Статус сборки CUDA-образа и результаты проверок
зафиксированы в PR.

Сквозная проверка требует разрешённого LoRA с конфигурацией и полного
снимка базовой модели. Загрузка крупных файлов с CDN завершалась
ошибками TLS. Состояние документов на сканах и результаты XLSX нужно
подтвердить через рабочий обработчик после получения артефактов.
