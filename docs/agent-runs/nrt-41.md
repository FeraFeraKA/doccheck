# NRT-41 — базовый Docker Compose

[Задача Linear](https://linear.app/andreiakimov/issue/NRT-41/docker-compose-karkas-i-zapusk-ml-modulya-s-gpu) прочитана напрямую 13.11.2026 в 04:13 МСК. Назначение `n90-20261112-2352 / a2`, база `b58025e443386b9c2ce26b20b1d7d99b3b94197f`.

Подготовлен синтетический срез на базе NRT-8. `compose.yaml` запускает
PostgreSQL с постоянным volume, миграцию по готовности БД, отдельные API и
worker, затем frontend с nginx. Опубликован только loopback-порт frontend.
Обычный `down` сохраняет том. Код обработки и HTTP-контракт остались прежними.

Оба Dockerfile используют закреплённые digest и lockfile. `.dockerignore`
разрешает только необходимые пути исходников и сборки. Примеры, локальные
данные, секреты, holdout, модель и веса исключены. Оригиналы хранятся отдельно
в `data/`, загрузка и сохранение файлов в этом срезе отсутствуют.
Команды запуска и проверки описаны в README. Версии и ссылки на лицензии
основных компонентов приведены в [backend/README.md](../../backend/README.md#docker-compose).

На Windows/amd64 Docker CLI 29.2.1 и Compose v5.0.2 проверили конфигурацию,
пять сервисов, зависимости готовности, сеть, порт и том PostgreSQL.
Docker Desktop 4.63.0 не запустил Linux Engine из-за ошибки локального
сокета `dockerInference`. Контейнерный запуск на этом хосте не подтверждён.
Первый Compose CI остановился на проверке контекста. После удаления широких
исключений для каталогов правила Docker Pattern Matcher подтвердили включение
17 нужных путей и исключение 18 посторонних. Actionlint проверил workflow.
В GitHub CI `Compose checks` предусмотрены чистая сборка на Linux/amd64,
проверка контекста через синтетические файлы, сценарий Chromium через nginx,
остановка и повторный запуск с проверкой сохранённого задания. Там же
фиксируются размеры образов, время сборки и запусков, снимок памяти.
Фактические результаты проверяются по журналу соответствующего запуска.

GPU, реальные OCR и Qwen inference, установка разрешённых весов, измерения
памяти модели и обработка пакета без внешней сети относятся к оставшейся
части NRT-41. Зависимости — готовый комплект и согласование с Семёном,
NRT-9 и проверка в целевой среде. Обучение не запускалось.
