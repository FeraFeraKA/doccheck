Мастер открывается по `/` и `/checks/new`. «Проверка системы» ведёт
на `/system-status`, где сохранён синтетический lifecycle. Прямой URL
добавлен в Vercel rewrite, синтетический Compose smoke перешёл туда же.
В основной навигации — новая проверка и обзор. URL журналов остались
доступными для старых ссылок.

Локальный мастер использует существующий multipart POST с КФЗ и
первичными документами. Ссылка на готовый пример открывает отдельный
синтетический результат. Публичная сборка показывает ограничение
передачи файлов внутри той же разметки и позволяет открыть пример.
В профиле обозначен «Бухгалтер» без вымышленного имени и сетевого
статуса. Список форматов соответствует нашему API. Переход к первичке
до выбора КФЗ отключён в локальном режиме. Варианты кнопки и иконки
адаптированы под существующий стек без новых npm-зависимостей.
Inter поставляется локально с OFL. Правила Docker включают только
задействованные локальные шрифты и текст лицензии.

Chromium при одинаковом viewport 1440×900 и 390×900 сравнил
[опубликованный референс](https://ananakimov.github.io/project-placeholder/)
с локальной рабочей сборкой. Снимки сохранены в игнорируемом
`data/nrt107-review/`: `source-1440.png`, `source-390.png`,
`local-1440.png`, `local-390.png`. Совпадают расположение и
пропорции оболочки, типографика мастера, панель и дропзона.
Отличаются подпись готового примера, разрешённые форматы, состояния
кнопок, подпись роли и техническая ссылка. Внутренний дизайн
обзора и результата остаётся отдельным срезом NRT-107.

Прошли lint, typecheck, 139 Vitest, 14 Playwright и production build.
Локальный Chromium-прогон публичной сборки подтвердил отсутствие
file input и POST при переходе к примеру, а также прямой маршрут
`/system-status`. Vercel rewrites проверены локальным импортом
конфигурации, без деплоя. Docker smoke локально не запускался.
