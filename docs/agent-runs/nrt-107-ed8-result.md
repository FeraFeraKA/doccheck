При переносе порядок взят из актуального исходника. Сохраняются три статуса показателя, отдельный статус выполнения, денежные строки и неизвестные значения из API. Счётчики и сводка берутся из ответа API. XLSX сохранён на «Документах» и по прямому маршруту `/conclusion`. Прочитанный исключённый дубль остаётся среди прочитанных. Синтетика маркируется на прямых маршрутах. Формула, причина, частичная сумма и точные адреса доступны в строке или контексте источника.

По Chromium на 390, 768 и 1440 px пройдены открытие сохранённого результата живого локального v3.2, частичная сумма с отдельными прочерками для ожидаемого значения и разницы, раскрытие слагаемого, абзац 6 акта, возврат фокуса, открытие того же акта из документов и XLSX. Прогон использовал сохранённый пакет из [проверки #89](https://github.com/VCyberPunk2077/doccheck/pull/89).

Ограничения. Метаданные типа документа, номера, даты, договора и числа страниц отображаются только если их надёжно даёт API. Текущий UI показывает гарантированные поля, включая роль, чтение и решение. PDF использует встроенный браузерный просмотрщик с переходом на указанную страницу. Слой bbox для PDF и полный встроенный предпросмотр XLSX/DOCX остаются отдельной работой. Сейчас офисный оригинал можно скачать, точный адрес показан рядом. Текстовый фрагмент из [#91](https://github.com/VCyberPunk2077/doccheck/pull/91) подключён: отображается адресный текст с UTF-8 подсветкой по подтверждённым границам. При отсутствии текста или точного совпадения доступны штатные состояния и оригинал. Принятие, архив, замена КФЗ, повторная проверка существующего комплекта и история версий требуют серверного жизненного цикла. Загрузка архивов отслеживается в [NRT-109](https://linear.app/andreiakimov/issue/NRT-109/soglasovat-priyom-arhivov-s-pervichnymi-dokumentami). Очередь и список находятся в [#93](https://github.com/VCyberPunk2077/doccheck/pull/93).
