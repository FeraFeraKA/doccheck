# NRT-106: отдельный режим двух чатов

- Задача: [NRT-106](https://linear.app/andreiakimov/issue/NRT-106/otdelnyj-flow-ispolnitel-i-nezavisimyj-revyuer-na-odnom-ustrojstve). Один исполнитель ведёт frontend и backend интеграции, другой чат независимо проверяет PR. Исполнитель продолжает независимые задачи во время ревью. По решению пользователя он может сливать свои PR в `main` после независимого ревью чата, Codex Code Review и проверок. ML/OCR остаётся направлением Семёна.
- Изменения: `docs/agents/two-chat/README.md`, ссылки в `AGENTS.md`, `CONTRIBUTING.md` и `README.md`; в общих документах также уточнено текущее состояние контракта, проверок и адрес репозитория. Ночной регламент не изменён.
- Проверки: `git diff --cached --check` прошёл; 24 локальные Markdown-ссылки в первоначальных изменениях и 10 в дополнении об автослиянии существуют. Сверены инструкции проекта и актуальные задачи Linear NRT-13, NRT-83, NRT-84, NRT-96, NRT-97, NRT-98, NRT-99, NRT-95 и NRT-70.
- Ограничение: режим описан, но два чата, доставка сообщений и полный цикл автослияния не запускались и не проверялись. Для прямой передачи и автослияния требуется явное разрешение пользователя; есть ручной fallback. Статусы других задач не менялись.
- Следующий шаг: независимое ревью документа и, после решения пользователя, проверка полного цикла на реальной задаче.
