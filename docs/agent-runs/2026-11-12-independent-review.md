# Инструкция независимого ревьюера

- Задача: подготовить правила независимого ревью для NRT-70 и пробный запуск без подключения нейроревью к CI.
- Файлы: `docs/agents/reviewer.md`, корневой `AGENTS.md` и этот отчёт.
- Уточнён выбор инструкций по области задачи и изменённым файлам: frontend, backend, их тесты, общие изменения и пересечение направлений.
- Проверки: `git diff --check`; отдельный агент без истории исполнителя проверил PR #2, base 65d44be и head 893ee31. Найдены два вероятных несоответствия NRT-14: отсутствие источников в таблице и отдельного примера ошибки файла. Агент выполнил два теста и typecheck, но не проверил браузер, сборку, экспорт, все примеры и точность рамки; ревью неполное.
- Ограничения: результат никому не отправлен и в PR не опубликован. Автоматический CI-статус, интеграция с Codex GitHub и повторный цикл исправлений ещё не настроены. Контракт не утверждён; личные ключи не использованы. Первый запуск обычного frontend CI остановлен GitHub до начала шагов из-за блокировки аккаунта по вопросу биллинга.
- Следующий шаг: проверить замечания и недостающие пункты, согласовать способ публикации ревью; после решения вопроса с GitHub Actions повторить запуск. Затем отдельно подключить автоматизацию.
