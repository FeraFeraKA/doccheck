и связанные NRT-18, NRT-33 и NRT-40 прочитаны 13 ноября 2026 года.
Проверен код `46105e821fbee79a1a600d601cd5cb790d52f725` на Windows.
Инструкция тестировщика доступна в `docs/agents/tester.md` и связана с
`AGENTS.md`. Машинный контракт результата — `doccheck-check-result/1`.
Правила в результатах тестового адаптера и синтетического примера
предназначены для фикстур.

## Сопоставление с продуктовыми сценариями

Краткие цели групп взяты из раздела 6
[«Данные, контракт и приёмка»](https://linear.app/andreiakimov/document/dannye-kontrakt-i-priyomka-1c729510a76b).
Подписанная ссылка на `acceptance_scenarios.json` перенаправляет
на HTML Linear. Исполняемая спецификация и подтверждение версий
сценариев в доступных материалах отсутствуют. Статусы ниже относятся к
группам и уровню доказательств. Отдельные A01–A16 не запускались.

| Группа | Подтверждённые проверки компонентов | Открытая часть приёмки |
| --- | --- | --- |
| A01, исходный комплект | Pydantic и JSON Schema принимают версионированный пример. Встроенный пример показывает расхождение, исключения и адрес доказательства. | Сквозная сверка исходного комплекта и независимая разметка недоступны для этого прогона. |
| A02–A05, имена и дубли | Контракт отклоняет повторное слагаемое по тому же адресу и сумму из байтовой копии. Публичный комплект различает байтовую копию и разные операции с равной суммой. | Рабочий pipeline на перестановке, переименовании и неоднозначном повторе не запускался. |
| A06, область | Проверены ограничения доказательства по договору и периоду, в том числе недопустимость использовать КФЗ вместо первичного подтверждения. Генератор содержит публичные варианты другого договора и периода. | Извлечение реквизитов и исключение файлов в рабочем pipeline не проверены. |
| A07–A09, полнота и иерархия | Контракт отклоняет подстановку нуля при неполной строке и подтверждение при конфликте чтений; публичная фикстура включает совпадение наблюдаемой суммы при отсутствии обязательного источника. UI различает ноль и прочерк. | Удаление файла из рабочего пакета и отсутствие двойного учёта родителя с детализацией не проверены сквозным тестом. |
| A10–A12, формулы и дефекты | Верификатор проверяет формулу и кэш готовой XLSX; API принимает предусмотренный повреждённый OOXML для последующей пофайловой обработки. Worker с тестовым адаптером сохраняет частичную ошибку. | Вычисление SUM без кэша и обработка неподдерживаемой формулы либо нечитаемого реквизита реальным обработчиком не проверены. |
| A13–A15, изменения значений | Контракт проверяет точные отрицательные значения, доказанный ноль, противоречащие единицы и арифметические связи. Генератор и каталог тестируют варианты входов. | Чувствительность результата рабочего pipeline к независимым мутациям первички и КФЗ не измерялась. |
| A16, воспроизводимость | Установка frontend из локального кэша и сборка прошли. | Полный офлайн-прогон с готовыми весами и очищенным кэшем результатов недоступен. Локальный Docker daemon не запущен. |

Ложные подтверждения проверены на отрицательных случаях технического
контракта. Его валидатор отклоняет заявленное `verified` при конфликте
доказательств, а публичная фикстура удерживает совпавшую частичную сумму
в `unverified`. Частота ложных подтверждений, доля покрытия A01–A16
и точность на продуктовых данных неизвестны. Для них нужны согласованные
сценарии, знаменатель и прогон независимого комплекта владельцем данных.
Измерение памяти и времени рабочего pipeline не проводилось.

В выполненных проверках дефектов продукта не обнаружено. Закрытый
эталон оставался вне прогона. Публичные ожидаемые ответы не изменялись.
