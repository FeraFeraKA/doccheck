# NRT-70 и NRT-90: взаимное ревью ночных PR

- Подготовлен порядок для полной согласованной очереди: автор проверяет свои изменения до коммита, противоположный worker публикует независимый отзыв, координатор ждёт также Codex Code Review и интеграционный CI.
- По GitHub read-only подтверждено: PR #6 (`worker-a`) получил отзыв ревьюера координатора и ручной запуск Codex; PR #7 (`worker-b`) получил опубликованную автором внутреннюю проверку, отзыв ревьюера координатора и автоматический запуск Codex. Сводки бота показывают завершение на соответствующих head без нерешённых замечаний.
- Уточнены передача ревью через Linear, идентификация учётных записей, повторная проверка при изменении базы, сохранение прошлых результатов и восстановление после STOP. Начальные промпты переключены с пилота на обычную ночную очередь.
- Пример фильтра проверен на восьми синтетических событиях ревью и восстановления; независимый ревьюер проверил дополнительные сценарии и после исправлений вынес `pass`. `git diff --check`, относительные ссылки и заголовки в 12 Markdown-файлах, а также стартовые промпты полноценной очереди прошли проверку.
- Новое взаимное ревью, ручной fallback Codex, перенос результатов и полноценный запуск на двух устройствах не проводились. Linear и GitHub в этой работе не изменялись; это не приёмка NRT-70 или NRT-90.
