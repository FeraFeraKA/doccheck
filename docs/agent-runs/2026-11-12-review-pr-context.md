# Контекст Linear для ревью через PR

- Задача: передавать ревьюеру цель и критерии задачи через описание PR, подготовленное автором по Linear.
- Файлы: `AGENTS.md`, `CONTRIBUTING.md`, `docs/agents/reviewer.md` и этот отчёт.
- Проверка: `git diff --check` и сверка правил автора и ревьюера; фактический прогон встроенного Code Review с новым форматом не выполнялся.
- Ограничения: ревьюер не подтверждает актуальность копии в PR без прямого доступа к Linear. Закрытые данные и секреты публиковать нельзя.
- Следующий шаг: проверить новый формат на тестовом PR; обновить связанную задачу Linear после согласования.
