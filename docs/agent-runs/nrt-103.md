## Результаты

В пяти вопросах поиск указал на исходники или действующую инструкцию. В
таблице указаны строки и приблизительный объём результата в токенах.
Оценка равна размеру нормализованного вывода в байтах UTF-8, делённому на
четыре с округлением вверх. Это ориентир объёма для сравнения, без замера
токенизатора и без стоимости чтения файлов. Префикс SHA в `git grep`
увеличивает вывод по сравнению с `rg`. Для оценки нужны ещё строки вокруг
найденного места и применимые инструкции.

| Вопрос | Широкий `git grep` | По карте `git grep` | По карте `rg` | Куда ведёт поиск |
| --- | ---: | ---: | ---: | --- |
| Где объявлены и реализованы маршруты запусков? | 48 / 1777 | 18 / 609 | 18 / 425 | `api.py`, OpenAPI |
| Где запрос истории, курсор и остановка опроса? | 43 / 1708 | 20 / 816 | 20 / 611 | `checkData.ts`, `runStatusApi.ts`, тесты клиента |
| Где отдельный worker получает задание и восстанавливает прерванное? | 15 / 573 | 15 / 573 | 15 / 419 | `run_worker.py`, тесты worker, руководство запуска |
| Где проверки ожидаемой суммы и статуса `unverified`? | 60 / 2424 | 43 / 1679 | 43 / 1238 | Pydantic-модели и тесты контракта |
| Когда исполнитель может слить PR и какие SHA проверять? | 14 / 3854 | 14 / 3854 | 14 / 3711 | Глава «Автоматическое слияние в main» и инструкция ревьюера |

Уточнение пути и слов помогает по первым двум вопросам. Для денежного
контракта поиск всё ещё даёт 43 строки, поэтому стоит начинать с определения
`class ResultRow` и переходить к связанным тестам. Длинные абзацы регламента
оставляют большой вывод даже на узких путях. Заголовок
`^## Автоматическое слияние` приводит к нужной главе одной строкой. Запрос
«Почему экран перестал обновляться после завершения проверки?» дословно
ничего не нашёл. Карта даёт срез `pages/checks`, а поиск по `pollRun` указывает
на функцию. Отдельная выборка путей `git ls-tree` нашла 25 файлов в `pages/checks`
и `backend/src/doccheck_backend`.

## Как повторить

Запустите PowerShell из корня чистого worktree проверенного коммита.
Для `git grep` достаточно, чтобы коммит был доступен локально. Для сравнения
с `rg` текущие файлы должны соответствовать тому же дереву. Измерено на Git
2.45.1.windows.1 и ripgrep 15.2.0.

```powershell
$rev = '208fdf7df8387cb5b5127ec0ac8f05c41527c7bf'
$allow = @('AGENTS.md','README.md','CONTRIBUTING.md','compose.yaml','frontend/src','frontend/tests',
    'backend/src','backend/migrations','backend/tests','backend/README.md','backend/ml_module/README.md',
    'contracts/README.md','contracts/doccheck-api.v0.openapi.yaml','docs/architecture.md',
    'docs/data-policy.md','docs/case/README.md','docs/agents/reviewer.md','docs/agents/two-chat/README.md',
    '.github/workflows')
$questions = @(
  @{ name = 'Routes'; pattern = '/api/v0/runs'; scope = @('backend/src/doccheck_backend/api.py','contracts/doccheck-api.v0.openapi.yaml') },
  @{ name = 'History'; pattern = 'pollRun|next_cursor|GET /api/v0/runs'; scope = @('frontend/src/pages/checks','frontend/tests/unit/run-status-api.test.ts') },
  @{ name = 'Worker'; pattern = 'run_document_worker|SKIP LOCKED|processing_interrupted'; scope = @('backend/src/doccheck_backend/run_worker.py','backend/tests/test_run_worker.py','backend/README.md') },
  @{ name = 'Money'; pattern = 'expected_value|unverified'; scope = @('backend/src/doccheck_backend/contracts/result.py','backend/tests/test_result_contract.py') },
  @{ name = 'Review'; pattern = 'base/head|Codex Code Review'; scope = @('docs/agents/two-chat/README.md','docs/agents/reviewer.md') }
)
function Measure-Search($lines) {
  $bytes = [Text.Encoding]::UTF8.GetByteCount($lines -join [char]10)
  "$($lines.Count) / $bytes / $([math]::Ceiling($bytes / 4))"
}
foreach ($question in $questions) {
  $broad = @(git grep -InE -e $question.pattern $rev -- @allow)
  if ($LASTEXITCODE -ne 0) { throw 'Unexpected broad search result' }
  $scope = $question.scope
  $focused = @(git grep -InE -e $question.pattern $rev -- @scope)
  if ($LASTEXITCODE -ne 0) { throw 'Unexpected focused search result' }
  $live = @(rg --no-config --color never --no-heading --with-filename --line-number -e $question.pattern -- @scope)
  if ($LASTEXITCODE -ne 0) { throw 'Unexpected rg result' }
  "$($question.name): $(Measure-Search $broad) | $(Measure-Search $focused) | $(Measure-Search $live)"
  $focused | ForEach-Object { ($_ -split ':', 4)[1] } | Sort-Object -Unique
}
git ls-tree -r --name-only $rev frontend/src/pages/checks backend/src/doccheck_backend
git grep -InF -e 'Почему экран перестал обновляться после завершения проверки?' $rev -- @allow
"Exact phrase exit status: $LASTEXITCODE"

git grep -InF -e 'pollRun' 75e2bd481a51cb815ea3ef57f5619385336d5484 -- frontend/src/pages/checks
"Before NRT-100: $LASTEXITCODE"
git grep -InF -e 'pollRun' $rev -- frontend/src/pages/checks
"After NRT-100: $LASTEXITCODE"
```

## Обновление и границы

Сравнение снимков до и после NRT-100 подтвердило обновление выборки сразу
при смене SHA. В `75e2bd4` поиска `pollRun` нет, в `208fdf7` он возвращает три
строки с путями и номерами. `rg` следует использовать для файлов рабочей копии.
При изменении точки входа или сценария уточняйте карту после получения свежего
коммита и перепроверяйте относительные ссылки.

На этом наборе вопросов достаточно `git ls-tree`, `git grep` и `rg`.
Отдельный индекс и семантический RAG пока не нужны. Их стоит измерить,
если на расширенном наборе вопросов с пользовательской лексикой карта и
уточнённые термины регулярно не приводят к нужным исходникам. Замер не
оценивает качество ответов ассистента и не покрывает все формулировки.

Во время оценки поиск оставался локальным и ограничивался перечисленными
исходниками, синтетическими тестами и текстовыми инструкциями. Поиск не
включал `.env`, `data/`, OCR-кэши, исходные документы, закрытые результаты и
независимые эталоны. `git check-ignore` подтвердил исключения для `.env`,
`data/`, `holdout/` и `.worktrees/`. Перечень путей, правила доступа и проверка
вывода остаются необходимыми, даже если Git исключает путь из добавления.
Перед задачей прочитайте обязательные AGENTS.md, актуальные источники и
предписанные примеры отдельно по [режиму данных](../data-policy.md).

Изменена документация. Проверены локальные ссылки и `git diff --check`.
