# NRT-97 — чтение состояния, результатов и источников

[NRT-97 в Linear](https://linear.app/andreiakimov/issue/NRT-97/api-poluchat-sostoyanie-rezultat-i-istochniki-zadaniya)
и NRT-13 прочитаны 13 ноября 2026 года.

## Цель и критерии

Предоставить frontend согласованный доступ к состоянию сохранённого
задания, его результату и источникам.

- [ ] По ID возвращаются фактическое состояние, результат и ошибки.
  Состояние задания отделено от статусов показателей.
- [ ] Документы и адресные фрагменты относятся к указанному заданию.
  Произвольные пути к файлам не раскрываются.
- [ ] Для отсутствующего задания, неготового результата и недоступного
  источника возвращаются ошибки. Неизвестные значения не подменяются нулями.
- [ ] История запусков следует HTTP-контракту NRT-13.
- [ ] Автоматические проверки охватывают готовое и незавершённое задания,
  ошибки и границу доступа к файлам.

## Изменения

- История читается из PostgreSQL с непрозрачным курсором по дате и UUID.
  Прогресс в состоянии равен нулю для очереди и итогу для завершённого
  запуска. Для обработки и сбоя числовой прогресс пока недоступен.
- Результат и доказательства возвращаются из сохранённого
  `CheckResult`. Десятичные строки, `null`, пометка синтетики,
  файловые ошибки и адреса сохраняются.
- Оригинал принадлежит манифесту запуска. Путь строится только из
  серверных идентификаторов и проверяется перед потоковой выдачей.
  Фрагмент должен относиться к этому документу и доступному оригиналу.
- Просмотрены все 25 файлов разрешённого комплекта, включая сканы КФЗ
  и формы с адресами PDF, PNG, XLSX и DOCX. В тестах использована синтетика.

Рабочий адаптер относится к NRT-95. Скачивание XLSX результата относится
к NRT-36. Прогресс по отдельным файлам worker пока не сохраняет.
