# NRT-43. Локальная сверка v3.2 через браузер

[Критерии NRT-43](https://linear.app/andreiakimov/issue/NRT-43/skvoznaya-integraciya-i-knopka-demo), проверены 14.11.2026. Этот срез проверяет ручную загрузку КФЗ и акта, реальный путь API → PostgreSQL → отдельный worker → v3.2 → API → браузер и открытие первичного источника. Полный набор кейса и кнопку запуска примера следует проверить отдельно.

Из корня репозитория с Python 3.12 и uv:

```powershell
uv run --python 3.12 --with-requirements bench/e2e_v32_20261114/requirements.txt python frontend/tests/live/create-fixtures.py
```

Запустите локальный сайт с подключённым v3.2. Для теста нужен рабочий адрес `http://127.0.0.1:8080`; другой локальный порт можно задать переменной `DOCCHECK_LIVE_URL`. Из `frontend/` выполните:

```powershell
pnpm install --frozen-lockfile
pnpm exec playwright install chromium --only-shell
pnpm exec playwright test --config=playwright.live.config.ts --grep 'first package'
```

Для обоих пакетов опустите `--grep`. У каждого пакета синтетический КФЗ XLSX на 10 000,00 ₽ и один синтетический акт DOCX. Первый акт содержит 9 000,00 ₽ для договора TEST-5, второй содержит 8 112,50 ₽ для договора TEST-6. Файлы создаются на месте в `data/nrt-43-live/`. Тест отправляет оба файла через мастер без формы ручного ввода области. Он ждёт сохранённую сверку, проверяет частичную сумму и статус «Не проверен», открывает абзац 6 акта и сравнивает ответ сервера с байтами отправленного DOCX.

Результат браузерного прогона сохраняется в `frontend/test-results/`: идентификатор задания, снимок строки сверки и снимок открытого источника. Для диагностики передавайте только сведения о синтетических прогонах.

Проверено на Windows с Python 3.12, pnpm 12.14.0 и Playwright 1.65.0. Генерация файлов, TypeScript, lint и оба браузерных сценария прошли. Каждый тест запускался отдельной командой с конфигурацией `playwright.live.config.ts`, которая не запускает свой веб-сервер и обращается к действующему адресу `127.0.0.1:8080` без перехвата запросов.

- Первый пакет завершён за 8,4 с по отчёту Playwright, включая браузерные проверки. После HTTP 202 таблица сохранила 9 000,00 ₽ как частичную сумму. Абзац 6 открылся, байты акта совпали.
- Второй пакет завершён с изменённым договором, номером акта и 8 112,50 ₽ частичной суммы. Абзац 6 открылся, байты акта совпали.
- В локальном журнале Ollama оба вызова `/api/chat` вернули HTTP 200. Время вызовов составило 5,03 с и 2,30 с. Модель была загружена в GPU. Этот замер относится к двум маленьким синтетическим пакетам.

Проверены ручная загрузка и открытие результата с источником. Полная независимая приёмка, работа со сканами, полные комплекты и отдельная кнопка запуска примера остаются вне этого прогона.
