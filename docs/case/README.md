# Сверка фактических затрат

Бухгалтер сверяет карточку фактических затрат (КФЗ) с первичными документами: например, актами и ведомостями. Цель — понять, какие суммы подтверждаются и какие строки нужно разобрать вручную.

1. Бухгалтер загружает КФЗ и первичные документы за нужный договор и период.
2. DocCheck собирает суммы по статьям, сравнивает их с КФЗ и показывает, откуда взялось каждое число: из какой страницы, строки или ячейки.
3. Бухгалтер проверяет расхождения по источникам, запрашивает недостающие документы и принимает итоговое решение.

Сверка сравнивает фактические затраты за один договор и период. Если факт ниже плана и обе фактические суммы совпадают, расхождения нет. При неполном подтверждении статья требует ручной проверки. Ожидаемое поведение и ограничение текущего обработчика описаны в [учебных сценариях](use-cases.md).
