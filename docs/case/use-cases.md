# Два учебных сценария сверки

Возьмите [учебный комплект](../synthetic/nrt-89/README.md): `inputs/01_kfz.pdf` и 22 первичных документа с ролью `supporting` из [списка файлов](../synthetic/nrt-89/inputs.json). Договор — `SYN-00890041-КФ/47`, период — 01.06.2036–31.10.2036, этап — 7. Статьи и итог находятся на странице 1 КФЗ.

В разделе «Новая проверка» добавьте файлы и нажмите «Запустить проверку». Для расчёта нужен обработчик, который поддерживает сканы КФЗ. Если строку КФЗ не удалось определить однозначно, уточните её в карточке проверки. [Запуск DocCheck](../../README.md#запуск-каркаса-через-docker-compose) · [Запуск с обработчиком документов](../docker.md)

## 1. Загрузить весь опубликованный комплект

Загрузите КФЗ и все 22 первичных файла. Сверьте сохранённый результат с [ожиданиями учебного комплекта](../synthetic/nrt-89/expectations/manifest.json).

| Статья | КФЗ, ₽ | По документам, ₽ | Ожидаемый результат |
| --- | ---: | ---: | --- |
| Оплата труда | 986 204,37 | 986 204,37 | Совпадает |
| Страховые взносы | 297 880,85 | 297 540,37 | Расхождение: 340,48 ₽ |
| Общепроизводственные расходы | 215 010,33 | 215 010,33 | Совпадает |
| Общехозяйственные расходы | 227 070,15 | 227 070,15 по доступным документам | Не проверено: нет полного подтверждения |
| Прочие расходы | 13 910,05 | — | Не проверено: нет источников |

В этих двух непроверенных статьях манифест оставляет полную сумму и разницу пустыми. Если обработчик считает комплект полным, он берёт за сумму первички 0,00 ₽ по статье без допущенных документов. При ненулевой сумме в КФЗ он покажет расхождение. Такую строку бухгалтер проверяет вручную.

- Откройте источники страховых взносов: страница 1 КФЗ и ячейки `B6` листа «Расчет взносов» в файлах `03_insurance_06.xlsx`–`03_insurance_10.xlsx`. Расхождение относится к статье, которая входит в «Итого». Подтверждать весь итог можно, когда подтверждены все его статьи.
- На вкладке «Документы» выберите «Исключены» и проверьте решения по файлам. `10_admin_copy.pdf` — дубль `09_admin_act.pdf`, `13_transfer.pdf` — другой договор, `14_admin_act.pdf` — другой период.
- Когда бухгалтер проверит результат, он может нажать «Принять и скачать заключение» на вкладке «Результат». Сверьте в XLSX статусы, разницы и адреса источников.

Пример с планом: если план по оплате труда равен 1 000 000,00 ₽, а подтверждённый факт и КФЗ равны 986 204,37 ₽, разница при сверке составляет 0,00 ₽. План здесь приведён для пояснения и отсутствует во входных файлах.

## 2. Заменить один акт повреждённым PDF

С установленным `uv` выполните из корня репозитория. Если папка для результата уже существует, укажите в `--output` новый путь.

```sh
uv run --python 3.12 --no-project --with openpyxl==3.1.5 --with et-xmlfile==2.0.0 --with pillow==13.0.0 python research/negative-fixtures/generate.py --output data/negative-fixtures-check
```

Создайте новую проверку с тем же комплектом, заменив только `inputs/04_act.pdf` на `data/negative-fixtures-check/inputs/truncated_act.pdf`.

В «Документах» ожидается ошибка чтения акта, а в статье «Общепроизводственные расходы» — статус «Не проверен» (`unverified`). В КФЗ указано 215 010,33 ₽, по трём доступным источникам получается 138 633,62 ₽. Полная сумма и разница остаются пустыми. Если результат сохранён, проверьте те же значения и ошибку в выгрузке XLSX. Решение о дальнейших действиях принимает бухгалтер.
