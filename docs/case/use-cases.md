# Два учебных сценария сверки

Оба сценария используют [учебный комплект](../synthetic/nrt-89/README.md) с
вымышленными данными. Из папки `docs/synthetic/nrt-89/` выберите
`inputs/01_kfz.pdf` как КФЗ и 22 первичных документа с ролью `supporting`
из [списка файлов](../synthetic/nrt-89/inputs.json). Не загружайте манифест
ожиданий и служебные файлы как документы.

Учебная область — договор `SYN-00890041-КФ/47`, период 01.06.2036–31.10.2036,
этап 7. Статьи и итог находятся на странице 1 КФЗ. Для получения результата
запустите [Compose с обработчиком документов](../docker.md): обычный
`docker compose up` без GPU-конфигурации оставляет пакет в очереди.

В разделе «Новая проверка» добавьте файлы и нажмите «Запустить проверку».
Если строку КФЗ не удалось определить однозначно, уточните её в карточке
проверки.

## 1. Полный пакет: найти расхождение

Загрузите КФЗ и все 22 первичных файла. Сверьте сохранённый результат с [ожиданиями учебного комплекта](../synthetic/nrt-89/expectations/manifest.json).

| Статья | КФЗ, ₽ | По документам, ₽ | Ожидание учебного комплекта |
| --- | ---: | ---: | --- |
| Оплата труда | 986 204,37 | 986 204,37 | Совпадает |
| Страховые взносы | 297 880,85 | 297 540,37 | Расхождение: 340,48 ₽ |
| Общепроизводственные расходы | 215 010,33 | 215 010,33 | Совпадает |
| Общехозяйственные расходы | 227 070,15 | 227 070,15 по доступным документам | Не проверено: нет полного подтверждения |
| Прочие расходы | 13 910,05 | — | Не проверено: нет источников |

В этих двух непроверенных статьях манифест оставляет полную сумму и разницу пустыми. Если обработчик считает комплект полным, он берёт за сумму первички 0,00 ₽ по статье без допущенных документов. При ненулевой сумме в КФЗ он покажет расхождение. Такую строку бухгалтер проверяет вручную.

- Откройте источники страховых взносов: страница 1 КФЗ и ячейки `B6` листа «Расчет взносов» в файлах `03_insurance_06.xlsx`–`03_insurance_10.xlsx`. Расхождение относится к статье, которая входит в «Итого». Подтверждать весь итог можно, когда подтверждены все его статьи.
- На вкладке «Документы» выберите «Исключены» и проверьте решения по файлам. `10_admin_copy.pdf` — дубль `09_admin_act.pdf`, `13_transfer.pdf` — другой договор, `14_admin_act.pdf` — другой период.
- Когда бухгалтер проверит результат, он может нажать «Принять и скачать заключение» на вкладке «Результат». Сверьте в XLSX статусы, разницы и адреса источников.

Пример с планом: если план по оплате труда равен 1 000 000,00 ₽, а подтверждённый факт и КФЗ равны 986 204,37 ₽, разница при сверке составляет 0,00 ₽. План здесь приведён для пояснения и отсутствует во входных файлах.

## 2. Повреждённый документ: сохранить частичный результат

Создайте новую проверку с тем же комплектом. Вместо `inputs/04_act.pdf`
загрузите [повреждённый учебный акт](../synthetic/nrt-89/variants/truncated_act.synthetic.pdf).
Остальные 21 первичный документ и КФЗ остаются прежними. Вариант намеренно
повреждён и предназначен только для этого сценария.

Запустите проверку и откройте «Документы»: у повреждённого акта должна быть
показана ошибка чтения. В «Результате» найдите «Общепроизводственные расходы».
Ожидается статус «Не проверен» (`unverified`): повреждённый документ не даёт
достаточного основания для полной суммы. Значения ниже относятся к учебному
набору при корректном чтении остальных трёх источников.

| Показатель | Ожидаемое значение |
| --- | ---: |
| В КФЗ | 215 010,33 ₽ |
| По трём прочитанным источникам | 138 633,62 ₽ |
| Полная сумма и разница | Не определены |

Откройте сохранившиеся источники и, если результат сохранён, проверьте те же
значения и ошибку в выгрузке XLSX. Решение о дальнейших действиях принимает
бухгалтер.
