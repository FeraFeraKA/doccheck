# Второму человеку: запуск worker-b на Mac

Тебе нужен один отдельный чат Codex на своём Mac. Координатор и `worker-a` запускаются у Николая; ты работаешь как **`worker-b`** под своей учётной записью.

## 1. Подготовь доступ

Убедись, что у тебя установлены Git и приложение ChatGPT с режимом Codex, а твоя учётная запись имеет доступ к [репозиторию DocCheck](https://github.com/VCyberPunk2077/doccheck) и проекту Linear. Используй собственную авторизацию: не проси и не передавай токены в чат.

Если репозитория на Mac ещё нет, клонируй его в удобную для тебя папку:

```sh
git clone https://github.com/VCyberPunk2077/doccheck.git
```

Если репозиторий уже есть, используй его и не удаляй свои незакоммиченные изменения. Попроси Николая сообщить имя ночной ветки и полный SHA, которые подготовил координатор. Рабочий чат сначала получит эту ветку из GitHub и проверит SHA, а только потом будет читать инструкции; существующая локальная версия `main` может быть старее.

## 2. Открой рабочий чат

Открой приложение ChatGPT, выбери режим Codex и локальный проект `doccheck`. Создай отдельный чат и убедись, что ему доступны Linear и GitHub. Вставь:

```text
Ты рабочий агент worker-b ночного запуска DocCheck. Проверь доступ к Linear и GitHub и получи активный START из комментариев NRT-90. Получи базовую ветку из GitHub и проверь полный SHA от координатора. Если рабочая копия содержит чужие незакоммиченные изменения, не переключай и не перезаписывай её, сообщи о блокере. Перейди на точную версию инструкций только если это безопасно, затем прочитай docs/agents/nightly/README.md, docs/agents/nightly/protocol.md и docs/agents/nightly/worker.md. Сообщи мне о готовности.

Создай в этом чате одно плановое продолжение каждую минуту с точным коротким текстом работника из docs/agents/nightly/macos.md, подставив worker-b; проверь сохранённый текст и фактический запуск. Выполняй действующие назначения worker-b и запросы на ревью чужого PR по docs/agents/nightly/review.md, передавай ACK, RESULT или BLOCKED и открывай PR в целевую ночную ветку назначения. Не мёрж PR, не пушь в main и не ставь Done. При STOP подтверди остановку и останови плановое продолжение.
```

Когда чат подтвердит доступ и готовность, сообщи Николаю, что `worker-b` готов, и назови свои учётные записи Linear и GitHub, под которыми чат работает. Координатор сам отправит назначение через Linear; отдельно выбирать или начинать задачу не нужно.

## 3. Во время ночной работы

Оставь Mac включённым, без перехода в сон и подключённым к сети, а настольное приложение ChatGPT — открытым. Проверь, что в чате действительно создано плановое продолжение и оно сработало: один промпт не гарантирует, что чат будет проверять очередь всю ночь. Если Linear, GitHub или продолжение недоступны, сообщи Николаю и не выдавай запуск за успешный.

После получения задания worker должен подтвердить его, выполнить, открыть PR и передать координатору результаты. Для остановки по просьбе Николая проверь, что чат увидел `STOP`, отправил `STOPPED` и его плановое продолжение выключено в разделе Scheduled («Запланировано») приложения. Подробности — в [общей инструкции](README.md) и [порядке для рабочего агента](../agents/nightly/worker.md).
