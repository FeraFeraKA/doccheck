# Демо DocCheck за три минуты

Откройте [готовый учебный пример](https://doccheck-five.vercel.app/checks/synthetic-example). Он показывает результат на вымышленных данных и открывается без загрузки документов.

| Время | Что показать |
| --- | --- |
| 0:00–0:25 | Бухгалтер загружает карточку фактических затрат (КФЗ) и первичные документы. DocCheck сравнивает суммы по статьям и показывает их источники. |
| 0:25–1:25 | На вкладке «Результат» раскройте статью A: в КФЗ 150,50 ₽, по документам 120,50 ₽, разница 30,00 ₽. В КФЗ значение взято со страницы 1. Для каждого слагаемого откройте «Адреса и основание»: суммы стоят в ячейках `C6` и `C7` по 60,25 ₽. |
| 1:25–2:20 | У статьи B в КФЗ 0,00 ₽, но один из источников не прочитан. Сумма по документам и разница остаются пустыми. На вкладке «Документы» найдите `synthetic-scan.png` и покажите ошибку чтения. |
| 2:20–3:00 | Бухгалтер решает, какие расхождения разобрать и какие документы запросить. Следующий шаг — [проверить обработку двух учебных пакетов](case/use-cases.md) перед [пилотом](pilot-roadmap.md). |

В готовом примере видны адреса источников. В сохранённой проверке можно открыть доступные оригиналы и выгрузить результат в XLSX.

## Запуск демо без Docker

Установите Node.js и pnpm версий из [инструкции интерфейса](../frontend/README.md#установка-и-запуск). Из корня репозитория:

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm build
pnpm exec vite preview --host 127.0.0.1 --port 56553 --strictPort
```

Откройте [локальный пример](http://127.0.0.1:56553/checks/synthetic-example). Для него достаточно интерфейса. Если нужен API для загрузки файлов, используйте [Docker Compose](../README.md#запуск-каркаса-через-docker-compose).

Перед выступлением пройдите сценарий с таймером и приготовьте локальную запись на случай проблем со связью. Живую обработку показывайте после прогона с рабочим обработчиком: измените одну сумму в учебном документе, заново проверьте пакет и убедитесь, что разница изменилась ожидаемым образом. Скорость и точность называйте только по замерам с указанием размера выборки.
