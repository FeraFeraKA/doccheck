# Как показать DocCheck

Откройте [онлайн-версию DocCheck](https://responses-determined-prison-utilities.trycloudflare.com/checks/new). Для локального запуска используйте [Docker Compose с моделью](../README.md#запуск-doccheck-с-моделью-через-docker-compose).

1. На странице «Новая проверка» выберите карточку фактических затрат (КФЗ) и первичные документы. Для демонстрации можно использовать [учебные сценарии](case/use-cases.md) с вымышленными данными.
2. Запустите проверку и откройте её результат после обработки. Покажите суммы КФЗ и первичных документов, статусы и расхождения по статьям.
3. Откройте источники показателей и вкладку «Документы»: покажите, из каких документов взяты значения, какие документы исключены и какие требуют внимания.
4. После проверки результата скачайте заключение в XLSX. Уточнения по листам и контрольным значениям приведены в [учебных сценариях](case/use-cases.md).

Результат зависит от загруженных документов и доступности обработчика. Сведения о точности и скорости следует подтверждать измерениями на выбранной выборке.
