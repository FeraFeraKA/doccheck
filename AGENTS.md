# DocCheck: правила разработки

- Задача и её критерии в Linear определяют объём работы. Начинать с чтения README.md, CONTRIBUTING.md и относящихся к задаче документов.
- Если архитектура, дизайн, layout или scope не определены требованиями, спросить Николая до реализации. Ответа не ждать для независимой работы с уже согласованными требованиями; отсутствие ответа не считать согласованием.
- Один активный агент — отдельная ветка и worktree. Сохранять чужие изменения.
- Общий исходный контракт определён приложенной в Linear JSON Schema 0.1; сведения об источнике — contracts/README.md. Оригинальный файл пока не импортирован: это явный блокер задач контракта. Целевой путь — contracts/check_result.schema.json. Не создавать вторую несовместимую схему. Изменения контракта согласовывать с владельцем ядра.
- Денежная и предметная логика находятся в Python. Использовать Decimal или целые копейки; денежные значения в JSON — строки. Frontend не пересчитывает бухгалтерские суммы.
- Использовать PostgreSQL для заданий и результатов. SQLite не входит в согласованный стек.
- Статусы показателей: verified, discrepancy, unverified. Ошибки файлов и состояния заданий описываются отдельно. Отсутствие данных не означает ноль.
- Не коммитить оригиналы, эталоны, секреты, OCR-текст и реальные результаты. Не передавать закрытые данные в инструменты облачного агента. Подробнее в docs/data-policy.md.
- `.gitignore`, `.dockerignore` и отдельный worktree не изолируют файлы от чтения агентом. Закрытые материалы должны находиться вне доступной ему среды; соседняя папка при полном доступе не подходит.
- Синтетические фикстуры не выдавать за реальную обработку. Не изменять независимые ожидаемые ответы ради прохождения проверок.
- Проверять реально затронутое поведение. Не объявлять OCR, интеграцию, публикацию или приёмку успешными без результата соответствующей проверки.
- После работы сохранять краткий отчёт в docs/agent-runs/: задача, файлы, проверки, ограничения и следующий шаг. На приёмку передавать In Review; Done оставлять владельцу направления.
