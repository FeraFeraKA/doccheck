# Контракт результата

Контракт ядра, API и интерфейса ещё не зафиксирован. Присланные JSON Schema 0.1, `synthetic_result.json` и `acceptance_scenarios.json` — материалы для рассмотрения, не утверждённая реализация. Агенты могут разработать технический контракт по кейсу и доступному модулю, пройти независимое ревью и использовать его в ночной ветке; человеческую приёмку проводят владельцы обработки и интеграции. Не создавать вторую несовместимую схему и не выдавать техническое ревью за решение человека.

После технической проработки зафиксировать единый версионированный машинный контракт, синтетические примеры и проверки соответствия. Небольшой пример должен показывать необходимые для обмена поля и не выдаваться за результат обработки настоящего пакета. Публичные примеры не содержат независимых ожидаемых ответов.

На текущем этапе общие принципы: расчёты выполняются в Python с точной арифметикой; деньги передаются строками; неизвестное значение отличается от нуля; статусы показателей отделены от состояний задания и ошибок файлов; источники результатов должны быть адресными.
