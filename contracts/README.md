# Контракт результата

Контракт ядра, API и интерфейса ещё обсуждается владельцами обработки и интеграции. Присланные JSON Schema 0.1, `synthetic_result.json` и `acceptance_scenarios.json` — материалы для обсуждения, не зафиксированная реализация. До согласования не импортировать их как утверждённый контракт и не создавать вторую несовместимую схему.

После согласования зафиксировать единый машинный контракт, синтетические примеры и проверки соответствия. Небольшой пример должен показывать необходимые для обмена поля и не выдаваться за результат обработки настоящего пакета. Публичные примеры не содержат независимых ожидаемых ответов.

На текущем этапе общие принципы: расчёты выполняются в Python с точной арифметикой; деньги передаются строками; неизвестное значение отличается от нуля; статусы показателей отделены от состояний задания и ошибок файлов; источники результатов должны быть адресными.
