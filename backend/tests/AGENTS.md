# Правила тестирования backend

Действуют корневой `AGENTS.md`, `CONTRIBUTING.md` и инструкции направления backend, когда они появятся. Тесты backend, включая сквозные проверки через API без браузера, размещаются в `backend/tests/`; браузерные сценарии — в `frontend/tests/`.

Проверять затронутое поведение и согласованные критерии задачи. Использовать синтетические или явно разрешённые локальные данные; публичный CI использует только разрешённые синтетические фикстуры. Независимый эталон не включать в runtime и не менять ожидаемые ответы ради прохождения проверок. Фиксировать реально выполненные проверки и ограничения.

Подробный подход к проверкам обработки, OCR и моделей согласовать с Семёном; проверки API и интеграции — с Николаем. Не предполагать, что тесты или инструменты уже реализованы.
